# 分割した較正（D2）の推定誤差の評価（Outcasts >>52 §3 への応答）— 事前登録の契約（2026-10-11、計算前に固定）

（名前: 「V 検査」。再現を V0、小例を V1、測定を V2、判定を V3 とする。）

## 動機

Outcasts >>52 §3 の指摘: D 検査（`../Recalibration20261010/`）の D2 は、層ごとの比を探索用の標本（p < 10⁶）で推定し、確認用データ
（10⁶ < p < 2·10⁶）に当てた。>>47 では「確認用の f と独立に推定した比なので、P を固定した bootstrap がそのまま正当になります」と書いたが、
これは言い過ぎだった。標本を分けると「同じ標本で当てはめた偏り」（>>45 の小例の −1/8）は消えるが、推定した比 r̂_c と真の比 r_c の差は
同じ層の行で共有されるので、帰無仮説（行は独立、真の確率は P_i·r_c）のもとでも、同じ p・同じ層の 2 行の残差の積は平均で
P_i P_j Var(r̂_c) だけ正にずれる。>>52 の小例（訓練 2 行・検査 2 行、Bernoulli(1/2)）では真の平均が +1/8、plug-in の bootstrap では 0。
D2 の bootstrap は P^ex を真の確率として f* を引くので、このずれを 0 とみなす。そこで、(1) ずれの大きさを一次近似で見積もり、
(2) 比の推定ごとやり直す二段の bootstrap で D2 の p 値を出し直す。

## すでに見ているもの（正直に）

D 検査の結果をすべて見ている: D2 の観測値（T₂ = −160.186、T₃ = −49.696、T₄ = −3.575、S/E = 0.9995）、plug-in の帰無分布
（平均 −1.35 / 1.594 / −0.702、標準偏差 86.886 / 78.514 / 58.546、p = 0.056 / 0.505 / 0.978）、探索用と確認用の層ごとの比。
>>52 の小例（+1/8）は読んだが、こちらではまだ計算していない。**ずれの一次近似の値と、二段の bootstrap の分布は、一度も計算していない。**
新しい範囲は使わない（問いが D2 の手順そのものの較正なので）。

## 入力（固定）

- D 検査と同じ: 確認用データの全行（`../JointFailure20261008/confirmatory_rows.json.gz`）と探索用の行（`joint_test.load_exploratory()`）、
  モデル（H11 の `model`、B = 23、1 セル 10,000 標本、種 20261008）、行ごとの P_i と層（`../Stratified20261008/stratified_test.py` の `model_rows`、変更しない）。
- 層 = D2 と同じ（計算方法 × P_i の区間、`recalibration_test.cell_C3`）。手順 R も同じ: 層 c の比 r̂_c = Σ_{k∈c} f_k / Σ_{k∈c} P_k（探索用の行で。分母 0 なら 1、
  探索用で空の層は 1）。確認用の行の P^ex_i = clip(P_i·r̂_c, 0, 1)、決定的な行は P^ex_i = P_i。
- 統計量: J 検査の T₂・T₃・T₄（`joint_test.stats_arrays`）。

## 帰無仮説（この検査で較正するもの）

H₀^V: 探索用・確認用の全行は独立で、非決定的な行 k の失敗確率は P_k·r_c（r_c は層ごとの未知の定数、決定的な行は P_k）。
bootstrap では当てはめた比 r̂_c を真の値として扱う（パラメトリック bootstrap。比の推定の不確かさは入るが、層の中のずれ・層の切り方の選択は入らない）。

## 再現（止める条件）

- **V0**: D2 の手順（探索用の比 → 確認用の P^ex → `analyze_sample`、2,000 回、種 20261014）で、観測値 T₂ = −160.186、T₃ = −49.696、T₄ = −3.575（小数第 3 位まで）、
  S/E = 0.9995、帰無分布の平均と標準偏差（小数第 3 位まで）が D 検査の記録と一致すること。一致しなければ止める。

## 小例（>>52 の確認）

- **V1**: 訓練 n 行・検査 2 行、すべて Bernoulli(1/2) で独立、ĥ = 訓練の平均。有理数の厳密列挙で E[(F₁−ĥ)(F₂−ĥ)] を n = 2, 4, 8 で計算する。
  予測: 1/(4n)（n = 2 で +1/8、>>52 と一致）。plug-in（ĥ を与件に F* ~ Bernoulli(ĥ)）は 0。比較のため同じ標本での当てはめ（2 行、>>45）の −1/8 も並べる。

## 測定（判定に使わない）

- **V2（ずれの一次近似）**: clipping を無視し、r̂_c の分散を V̂ar(r̂_c) = Σ_{k∈c, 探索用} P^ex_k(1−P^ex_k) / (Σ_{k∈c, 探索用} P_k)² で見積もる。
  E[T₂] のずれ ΔE[T₂] = Σ_c V̂ar(r̂_c) · Σ_p Σ_{i<j, 同じ p, ともに層 c, 非決定的} P_i P_j。層ごとの寄与、確認用データの「同じ p・同じ層」の組の数、
  ΔE を D2 の帰無分布の標準偏差で割った値、ずらした後の Z = (T₂ の観測値 − (plug-in の平均 + ΔE)) / 標準偏差 を記録する。予測する向き: ΔE[T₂] > 0。
  T₃・T₄ のずれは一次近似では書かず、V3 の帰無分布の平均と plug-in の平均の差で測る。

## 判定（事前登録）

- **V3（二段の bootstrap）**: 再標本 b ごとに、(a) 探索用の行の f^tr* ~ Bernoulli(P^ex_tr)（P^ex_tr = clip(P_k·r̂_c)、決定的な行は P_k）を独立に引き、
  (b) f^tr* から手順 R をやり直して r̂*_c(b) を作り、確認用の行の P^ex*_i(b) = clip(P_i·r̂*_c(b)) を作り、(c) 確認用の行の f*_i ~ Bernoulli(P^ex_i) を独立に引き、
  (d) T_k(f*, P^ex*(b)) を記録する（2,000 回、種 20261016、乱数は (a) → (c) の順に引く）。
  観測値 T_k(f, P^ex) の両側 p 値 = 2·min(下側, 上側)（各側 (1 + #)/(R + 1)、J 検査と同じ式）。
  **判定**: k = 3, 4 で p ≥ 0.01 なら「比の推定の不確かさを含めても、D2 の判定（J1: 独立モデルとの違いは見えない）は変わらない」。
  k = 2 も同じ基準で並べる（J・D 検査と同じ扱い）。どれかが 0.01 未満ならその k と符号を報告する。
  あわせて、V3 の帰無分布の平均・標準偏差を plug-in（V0）と並べ、平均の差を V2 の ΔE[T₂] と比べる。

## 止める条件と上限

V0 の不一致で止める。1 プロセス、上限 30 分。層・モデル・種・回数は変えない。スクリプトの不具合で判定を書く前に止まった場合は、
D 検査と同じく記録（ログ）を残して直し、直した内容を README に書く。

## 主張しないこと

独立の証明、存在補題、標本外の素数への保証。V3 で p ≥ 0.01 でも、言えるのは「この有限範囲・この統計量・この層の切り方では、
比の推定の不確かさを含めても、低次の同時失敗にモデルの外の構造は検出されなかった」まで。層の中のずれ・層の切り方の選択・モデル（H11）自体の誤差は評価していない。
>>47 の「bootstrap がそのまま正当」は撤回し、D2 は「当てはめた比を与件にした診断」と読み替える。
