## 2. 紙の系（>>70 §3、>>73 §1）の監査

系: ℓ（最小の素数非剰余）を含み、ℓ の全有効平方候補の非剰余素因数について閉じた C（|C| = m）に対し p < 16^{2m}。
各段階を第三者として追った。**追えた。** 使っている仮定は >>72 の指摘どおり「ℓ の各有効候補が C の素数で割れる」という被覆だけで、他の頂点の閉性も局所失敗も使っていない。

| 段階 | 確認 | 境界の場合 |
|---|---|---|
| m = 1 は不可能 | t = 1 の候補 x = (p+σℓ)/4 は χ(x) = −1 なので非剰余素因数を持ち、ℓ ∤ x（ℓ ∣ x ⇔ ℓ ∣ p） | 12 素数で ℓ ∤ F(j)（0 ≤ j < ℓ）を数で確認 |
| F(j) = (p+σℓ)/4 + σℓ j(j+1) の mod r の根（r ∈ C∖{ℓ}） | 判別式 −σℓp。r ≠ 2, 3（剰余）、r ≠ ℓ、r < p なので非零。根は 0 か 2、j ↔ −1−j の対。固定点 j = (r−1)/2 では F ≡ p/4 ≢ 0 | r < 400 の非剰余素数（12 素数で延べ 435 個）で根 0/2・対・固定点なしを確認 |
| 対の区間誤差 < 1 | a < b = d−1−a、N = vd + s: 誤差 = [s>a] + [s>b] − 2s/d。s ≤ a で (−1, 0]、a < s ≤ b で (−1, 1)、s > b（b ≥ d/2 なので s > d/2）で (0, 1) | 1 素数の対（N ≤ 3r）と 2 素数の CRT 対（2 対、N ≤ 2d）で数で確認、各 15 組 × 12 素数 |
| 包除: \|Z − N∏(1−2/r)\| < (3^h − 1)/2 | k 個の積 d ごとに 2^k 根 = 2^{k−1} 対、各対の誤差 < 1、Σ_k C(h,k) 2^{k−1} = (3^h−1)/2。h = 0 は Z = N | C = {ℓ} ∪ 次の n 個の非剰余素数、N = 4^n、n = 1..5 で Z を直接数えて成立（h = 0 の場合も 670849・3678481・8615161 で出て Z = N） |
| 密度 ∏(1 − 2/r_i) ≥ ℓ/(ℓ+2h) ≥ 11/(11+2n) | r_i ≥ ℓ + 2i（ℓ より大きい相異なる奇素数）で ∏(r_i − 2)/r_i ≥ ∏(9+2i)/(11+2i) = 11/(11+2h)（望遠鏡） | n = 1..5 で数で確認 |
| Z > 0 | N = 4^n、主項 ≥ 4^n·11/(11+2n) ≥ 3^n、誤差 < (3^n − 1)/2 < 3^n | (1 + 2n/11)3^n ≤ 4^n を n ≤ 200 で厳密に、隣接比 3(2n+13)/(2n+11) ≤ 4 ⇔ −5 ≤ 2n |
| 矛盾 → 境界 | σℓ(2N−1)² < 3p なら t ≤ 2N−1 の候補は全部有効。C と互いに素な F(j) は χ = −1（χ(c) = χ(σ)χ(ℓ)χ(t)² = −1、p ∤ t）なので C の外の非剰余素因数（< p）を持ち被覆に反する。よって 3p ≤ σℓ(2N−1)² < 4σℓN² ≤ 12ℓ·16^{n} → p < 4ℓ·16^{m−1} | 候補の定義は c < 3p で等号を含まない。背理法の境界は ≥ のまま、(2N−1)² < 4N² で厳密化（>>73 の補足どおり） |
| ℓ ≤ ⌈√p⌉ | M = ⌈√p⌉ < p、0, ℓ, …, Mℓ の M+1 個の剰余を M 個の半開区間に。\|bℓ − ap\| < p/M ≤ √p ≤ M、1 ≤ b ≤ M。b と絶対剰余は ℓ 未満で素因数は剰余、χ(−1) = 1 なので χ(bℓ) = 1、一方 χ(b)χ(ℓ) = −1 | 12 素数で ℓ ≤ ⌈√p⌉（ℓ ∈ {11,13,17,19,23,31}、⌈√p⌉ ≥ 51） |
