## 3. 紙の系（>>70 §3、>>73 §1、README §2）の監査

一般の閉集合 C（ℓ ∈ C ⊆ V、|C| = m）についての系 p < 16^{2m}（m > log₂p / 8）は紙の証明なので、各段階を自分で追い、境界の場合を README に書く。有限で確かめられる部分は数で確かめる:

- 12 素数それぞれで ℓ = 最小の素数非剰余を求め、ℓ ≥ 11 と ℓ ≤ ⌈√p⌉ を確かめる（鳩の巣の証明は本文で追う）。
- F(j) = (p + σℓ)/4 + σℓ j(j+1) について、ℓ 以外の非剰余素数 r < 400 ごとに mod r の根を数え、0 個か 2 個、2 根は j ↔ −1−j の対、固定点 (r−1)/2 は根でない、判別式 −σℓp ≢ 0 (mod r)、ℓ ∤ F(j)（0 ≤ j < ℓ）を確かめる。
- 対になった根の区間誤差: 根の対 a < b = d−1−a（d は r、または 2 つの r の積の CRT）について、0 ≤ N ≤ 3d のすべての N で |#{0 ≤ j < N : j ≡ a, b} − 2N/d| < 1 を数で確かめる。
- 包除の評価: C = {ℓ} ∪ {ℓ の次の n 個の非剰余素数}（n = 1..5）、N = 4^n で、Z = #{0 ≤ j < N : gcd(F(j), ∏_C r) = 1} を直接数え、根を持つ素数の数 h ≥ 1 なら |Z − N∏_{active}(1 − 2/r)| < (3^h − 1)/2、h = 0 なら Z = N、いずれも Z > 0 を確かめる。r_i ≥ ℓ + 2i と ∏(1 − 2/r_i) ≥ 11/(11 + 2n) も数で確かめる。
- 算術の補題 (1 + 2n/11)·3^n ≤ 4^n を n = 0..200 で厳密に確かめ、隣接比 3(2n+13)/(2n+11) ≤ 4 を代数で確かめる。
- 境界: 3p ≤ σℓ(2N−1)² から p < 4ℓ·16^{m−1}（σ ≤ 3、(2N−1)² < 4N²）、ℓ ≤ ⌈√p⌉ ≤ 2√p から p < 16^{2m}/4 を代数で追う。
- 系が使っている仮定が「ℓ の候補が C の素数で割れる」という被覆だけであること（>>72 の指摘）を、証明のどの段階で何を使ったかの表で確かめる。
