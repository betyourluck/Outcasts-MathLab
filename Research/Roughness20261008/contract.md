# P1 / R: 小さい素因数を避けた ap+u は証人を持ちやすいか — 事前登録の契約（2026-10-08、計算前に固定）

（名前: 「R 検査」。判定を R1、測定を R2〜R4 とする。）

## 動機

Outcasts >>39 は、論文 021（Jacobsthal 関数の上界）を「小さい素因数を避ける a の数の下界」として、PR #7 の
`es_all_of_budget` の右辺（6 類の各素数で予算内に証人がある）に使う案を出した。しかし、

- >>33: ap+u が素数なら、証人があるためには a | u+1 が必要（約数が 1 と ap+u だけ）。
- H11（FailureAtlas）: 難しい素数の正体は「小さい素因数 × 大きい素数 1 つ」で、決定的に失敗する行。
- 証人を作るのは、法 4au で剰余が −1 になる**約数**。約数が多いほど機会は多い。

この 3 点からは、小さい素因数を避けることは、証人を持つうえで**不利**かもしれない。021 を使う方向の是非を、有限データで確かめる。

**すでに分かっていること（重複しない）**: Hlog（C(p) ≤ ⌈log₂ p⌉）は PR #4 の WitnessBudget20261001 で、1 億までの 179,468 素数で反例 0（ルナ側でも >>24 で再計算済み）。この検査は Hlog の真偽ではなく、**どの候補が証人を持ちやすいか**を見る。

## 入力（固定）

- **素数**: 2·10⁶ < p < 3·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529}（2,109 個。個数を数えただけで、ap+u はまだ計算していない）。
  この範囲は FailureAtlas（p < 10⁶）と J 検査（10⁶ < p < 2·10⁶）のどちらとも重ならない。
- **箱**: 互いに素な (a,u)、1 ≤ a, u、a·u ≤ B(p) = ⌈log₂ p⌉（この範囲では 21 または 22）。PR #4 の C(p) と同じ規約（互いに素）。
- **成否**: Dahan Theorem 3.9(ii)。ap+u を試し割りで完全に素因数分解し、指数まで含めた約数集合と 1..√(ap+u) の整数走査を照合する。不一致があれば止める。
- **z = 23**。p ≡ 1 (mod 24) なので、2 と 3 が ap+u を割るかは (a,u) だけで決まる（a+u の偶奇と mod 3）。そこで
  **「粗い」= ap+u が 5, 7, 11, 13, 17, 19, 23 のどれでも割れない**、と定義する。

## 判定（事前登録）

- **R1（021 の方向の是非）**: (a,u) ごとに層を分けた 2×2 表（粗い / 粗くない × 証人あり / なし）で、
  Cochran–Mantel–Haenszel（CMH）の共通オッズ比 OR_MH と CMH 検定（連続修正なし、自由度 1）を計算する。
  - 見立て（予測）: **OR_MH < 1**（粗い行のほうが証人を持ちにくい）。
  - 判定: CMH の両側 p < 0.01 かつ OR_MH < 1 なら「**避けることは不利**」、p < 0.01 かつ OR_MH > 1 なら「**避けることは有利**」、
    p ≥ 0.01 なら「差は見えない」。
  - 粗い行と粗くない行の片方しかない層（たとえば a+u が偶数でも 5〜23 の判定は変わるので通常は両方ある）は、CMH では自然に寄与 0 になる。層の数と、寄与した層の数を報告する。

## 測定（判定に使わない）

- **R2**: 証人ありの割合を、23 より大きい相異なる素因数の数 L（0, 1, 2, 3, ≥4）ごと、全体の ω ごとに並べる。L ≤ 1 の行の割合も。
- **R3**: 粗い行のうち ap+u が素数である割合と、その中で a | u+1 を満たす割合（>>33 の必要条件）。
- **R4（021 を候補集合に使った場合の一様性）**: 各 p について、R_p = 箱の中の粗い (a,u) の数、R_p^+ = そのうち証人のある数、
  N_p^+ = 箱全体で証人のある (a,u) の数。それぞれの最小値・分布と、R_p^+ = 0 の素数の数、N_p^+ = 0 の素数の数（後者は Hlog の反例。
  PR #4 の結果から 0 と見込む）。
- 感度（判定に使わない）: z = 7 と z = 100 での R1 の OR_MH と p 値。

## 止める条件と上限

2 方式の不一致があれば止めて原因を調べる。実行は 1 プロセス、乱数なし。上限 60 分。範囲・箱・z は広げない。

## 主張しないこと

存在補題、Hlog の真偽、021 の定理の誤り。R1 で「不利」と出ても、言えるのは「この範囲・この箱では、5〜23 を避けた ap+u は証人を持ちにくい」までで、
021 型の数え上げが役に立たないという主張ではない（避ける素数を選ぶ・避ける剰余を変えるなど、別の使い方は残る）。
