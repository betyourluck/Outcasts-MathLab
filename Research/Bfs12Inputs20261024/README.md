### 見立てで外れたこと

- 契約の J2 の理由で「根の τ が少ない **66529 が最も危ない**」と書いたが、66529 は根の τ = 3 で成功した（D = 0、候補 2 個）。τ = 1 が失敗することは契約の前に手で確かめていた。
  一方、根が全滅したのは **8615161（根 356 源）と 84525841（根 1115 源）**で、根の τ の多い入力だった。
  この 12 入力では、根の成功はほぼ τ = 1 の 1 源で決まっていて（下の測定）、根の τ の個数との関係は見えない。
  「根の τ が多い入力では子も多い」の部分はそのとおりで、子が数百あったので D = 1 で止まった。

## 測定（判定に使わない）

- **根の成功 S₀ はどの入力でも 0〜2**（根の τ が 1140 個ある入力でも 2 個まで）。根で成功した 9 入力のうち 8 入力で、最初の成功は τ = 1（66529 だけ τ = 3）。
  ほかに成功した根の源は τ = 3（670849）、τ = 7（5843041、53722321）、τ = 23（3678481）で、この 4 源はどれも Type I だけ。670849 は τ = 1 も Type I だけ。
- **子の頂点の成功は全部で 97 / 4,180（2.3%）**。成功した子の最初の成功 τ は 97 個中 85 個が τ = 1（88%、見立ての 8 割以上は当たり）。残りは τ = 3 が 7、τ = 5, 7, 13, 15, 29 が 1 個ずつ。
- **E₁′（根の失敗した源のうち、成功する子を持つものの割合）は 0.052〜0.21**（670849 の 5/97 から 1740481 の 72/343）。見立て「1 にならない」は当たり。
  E₁ は「成功する子が 1 個ある」ことで成り立っていて、根の源ごとに成功する子があるわけではない。
- **成功した子がどの根の源から来たか（D = 1 の 3 入力）**: 2521 は τ = 25、8615161 は τ = 29、84525841 は τ = 1。
  2 入力では、大きい τ の源が初めて小さい素因数（29、31）を供給し、その子の τ = 1 で成功した。
- **Hensel**: 調べた頂点と奇素数の組 3,057 個（k_ref ≥ 2）で v_max ≥ k_ref ≥ k₉₀、例外 0。>>90 の条件で k₉₀ ≥ 2 になるのは 2,938 組。
  改良した条件 A(r^k − 2)² < 3p で保証が 1 段上がる組が 141 個（2521 の (11, 3) は k₉₀ = 2、k_ref = 3、実現は v_max = 4 で τ = 25）。
  保証の外で実現した持ち上げ（v_max > k_ref）は 1,155 組。
