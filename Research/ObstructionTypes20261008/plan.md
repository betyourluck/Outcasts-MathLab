# (B) の失敗を型に分ける — 探索的な分類の計画（2026-10-08、計算前に固定）

**探索的な分類です。予測も判定もしません。** 入力は公開済みの M 検査の全行（`../ManyFactor20261008/manyfactor_rows.json.gz`、
3·10⁶ < p < 4·10⁶ の 2,082 素数、互いに素な (a,u)、a·u ≤ 22）で、M 検査の契約では見ていなかった「失敗の理由」を数える。新しい ap+u は計算しない。

## 定義（FailureAtlas の `failure_atlas.py` の `analyze` と同じ）

m = 4au、T = {q mod m : q は ap+u の素因数で gcd(q, m) = 1}（「使える」素因数）、⟨T⟩ は T が生成する (ℤ/m)^× の部分群、G² は平方の部分群。
失敗した行（証人なし）を次の 3 型に分ける。

- **QR 型**: −1 ∉ ⟨T ∪ G²⟩。ある奇な二次指標 χ で T ⊂ ker χ（群の障害、指標で書ける）。
  あわせて、負の d | 2au で「使える素因数 q がすべて (d | q) = 1」となる d を全部記録する（FailureAtlas の H4 と同じ）。
- **部分群型**: −1 ∈ ⟨T ∪ G²⟩ だが −1 ∉ ⟨T⟩（群の障害、指標では書けない）。
- **指数型**: −1 ∈ ⟨T⟩ だが、実際の指数では約数の剰余が −1 に届かない。各素因数を k 回まで使えるとき −1 に届く最小の k（k_min）と、
  実際の最大の指数との差を記録する。

あわせて、Outcasts >>37 の x 側の分類（I / II 枝の群条件と指数）と並べられるよう、件数は (a,u) 側の 3 型で数える。

## 集計

1. p = 3678481 の失敗した全組: 型、ω_使える、QR 型なら d、指数型なら k_min。
2. 全失敗行: 型の割合を ω_使える（1〜6）ごとに。
3. M 検査の事後解析で ω_使える ≥ 4 の組がすべて失敗した 4 素数（3613009, 3678481, 3900649, 3973729）の、その組の型。
4. ω_使える ≥ 4 の失敗行での、QR 型の d の分布と、指数型の k_min の分布。

## 主張しないこと

存在補題、型の割合の一般化。範囲・箱は M 検査のまま。
