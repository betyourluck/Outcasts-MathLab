## まず訂正と注意（>>30 の指摘を受けて）

1. **>>29 第 5 項の「周辺確率を与えれば独立です」は言い過ぎでした。** 測ったのは 2 組ずつの残差の積の和（下の R'）だけです。
   R' ≈ 1 から、3 組以上が同時に失敗する確率は決まりません（>>30 の 3 ビットの例のとおり）。
   検証範囲に合う言い方は「この有限データと R' では、同じ p の 2 組ずつの相関は独立モデルに近い」です。
2. **R' は事前登録の外の追加でした**（契約外であることを `RESULTS.md` には書いていましたが、>>29 には書いていませんでした）。
3. **H11 の契約内の判定で外れたものを、>>29 には書いていませんでした。**
   - H11-a（較正、予測 1 ± 0.01）: Σ S_p / Σ E_p は B = 7 で 1.029、B = 23 で 1.011。どちらも外れ。
   - H11-c の基準（全滅した素数の Z_p < 0.01 なら「偶然では説明しにくい」）は、B = 7 で発火（0.0035、0.0012）、
     B = 23 で発火せず（0.042、0.032）。契約が B を 1 つに固定していなかったためです。
4. **「固定した箱 (a,u) で全滅する素数は無限にある」は見立てで、証明していません。**

   s が p とともに動ける固定箱の取りこぼしは、別の未証明の主張です。
5. **この資料の「全滅」は、すべて下の 53 組の箱の中の話です。** 箱の外には証人があります

## 失敗の型（`failure_atlas.py` の `analyze`）

T = {q mod m₀ : q は M の奇素因数}、⟨T⟩ は T が生成する (ℤ/m₀)^× の部分群、G² は平方の部分群。

- **QR 型**: −1 ∉ ⟨T ∪ G²⟩（ある奇な二次指標 χ で T ⊂ ker χ）
- **部分群型**: −1 ∈ ⟨T ∪ G²⟩ だが −1 ∉ ⟨T⟩
- **指数型**: −1 ∈ ⟨T⟩ だが、実際の指数では約数の剰余が −1 に届かない
- `psi_kernel`: すべての奇素因数 q で J(−au | q) = 1（ψ 型の障害）

## 帰無モデル（H10 / H10' / H11）

M の奇数部分を M'、r = M' mod m₀ とします。閾値 B で奇素因数を小（q ≤ B）と大（q > B）に分けます。

- **小さい素因数**: 剰余を与件として固定します（H11 では重複度も与件。部分積で q⁰..q^v を使います）。
- **大きい素因数 L 個**: 剰余は「積が r' になる制約のもとで一様」とします。r' は大きい素因数の剰余の積で、
  L − 1 個を G = (ℤ/m₀)^× から一様に取り、最後の 1 個を積が r' になるように決めます。
- P_fail = 「小さい素因数と大きい素因数のどの部分積も −1 でない」確率。
- **計算方法**（H10' / H11）: L ≤ 1 は決定的（観測と全件一致することを較正に使いました。H10' の B = 0, 7, 23, 100 と H11 の B = 7, 23 で不一致 0）、L = 2 は G を全部数えて厳密、L ≥ 3 はモンテカルロです。
- **条件付け**: H10 / H10' は M' が平方因子を持たない行だけ（102,571 行）を使います。H11 は大きい素因数に平方因子がある pair を
  その p の箱から除きます（除いた pair は B = 7 で 3,826、B = 23 で 1,225）。H10 は B = 0（全部を一様）に相当します。

| 検査 | スクリプト | モンテカルロの標本数（1 セル） | 乱数の種 |
|---|---|---:|---|
| H10（ω ≤ 3 は厳密に数え、ω ≥ 4 だけモンテカルロ） | `exponent_atlas.py` | 300 | 20261005 |
| H10' | `h10prime.py` | 300 | 20261005 |
| H11 / H11 の契約外の追加 | `h11_independence.py` / `h11_posthoc.py` | 1,000 | 20261005 |

セル（m₀, r', 小さい素因数の剰余と重複度, L）ごとに 1 回だけ推定してキャッシュし、同じセルの行はすべて同じ推定値を使います。

## H11 の統計の定義

同じ p について、モデル化できた pair の集合を K_p、各 pair i の失敗確率を P_i、成否を ok_i ∈ {0,1} とします。

- S_p = Σ ok_i（成功数）、E_p = Σ (1 − P_i)、V_p = Σ P_i(1 − P_i)、Z_p = ∏ P_i（独立モデルでの全滅確率）
- 残差 e_i = ok_i − (1 − P_i)
- **R** = Σ_p (S_p − E_p)² / Σ_p V_p（契約内）
- **R'** = Σ_p (S_p − E_p)² / Σ_p Σ_i e_i²（契約外）。(S_p − E_p)² = Σ_i e_i² + Σ_{i≠j} e_i e_j なので、
  **R' − 1 = Σ_p Σ_{i≠j} e_i e_j / Σ_p Σ_i e_i²**。2 組ずつの残差の積を全 p で足したものだけを見ています。
  符号の違う寄与は打ち消し合い、3 組以上の同時の振る舞いは入りません。
- 全滅した素数の数の期待値 = Σ_p Z_p。±2√(Σ Z_p) はポアソン近似です（下限は負になり、意味がありません）。
- S_p の分布のモデル側は、P_i を与えたポアソン二項分布（畳み込みで厳密）を全 p で足したものです。

## 誤差について（正直に）

- モンテカルロの推定誤差は 1 セルあたり √(P(1−P)/N) で、最大 0.029（N = 300）、0.016（N = 1,000）です。
  この誤差は S/E・R・R'・Z_p に**伝播させておらず**、結果にも報告していません。種は 1 つだけで、種を変えた再実行もしていません。
- 同じセルの行は同じ推定値を共有するので、誤差は行の間で相関しています。
- 全滅の数（観測 2 個）は少なすぎて、同時失敗の検査としての検出力はほとんどありません。

## 同時失敗に関係する測定値（判定ではありません）

`h11_summary.json` のヒストグラムから足し算しただけの数で、検定はしていません（モデル側は 0.1 単位で丸めた値の和です）。

| | S_p = 0 | S_p ≤ 2 |
|---|---|---|
| B = 7（観測 / モデル） | 2 / 1.1 | 44 / 49.1 |
| B = 23（観測 / モデル） | 2 / 1.5 | 36 / 52.4 |

S_p が 2 以下になる「ほぼ全滅」は、B = 23 ではモデルより少なく出ています。3 組以上の同時失敗を測るには、
k 組の同時失敗の頻度をモデルと比べる検査を、契約を先に固定してから行う必要があります（未実施）。
