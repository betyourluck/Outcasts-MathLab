# P1 / H11: 固定した p で pair 間の失敗は独立か — 事前登録の契約（2026-10-05、計算前に固定）

H10' で、小さい素因数（3, 5, 7）の剰余を与件にすれば、各 (p, a, u) の失敗確率は帰無モデルで記述できた。
次の問い: **同じ p の異なる pair (a, u) の失敗は、モデルの周辺確率を与えれば独立か。**
独立なら「箱の全 pair で失敗する確率」は ∏ P_fail になり、難しい素数は偶然の産物。相関があれば構造的に難しい素数がある。

## 入力（固定）

- P1 の素数の行（(a,u) 互いに素 ≤ 6、23 pair）と H2' の行（u ∈ {11,13,17,19,23}、a ≤ 6、30 pair）。p は 840 の平方類の素数 2,370 個、箱は合わせて 53 pair。
- モデル: H10' と同じ。B = 7（主）と B = 23（感度）。小さい素因数は剰余と**重複度**を与件にする（部分積で q^0..q^v を使う）。
  大きい素因数（q > B）は重複度 1 のときだけモデル化できる（L − 1 個を一様、最後を積 = r' で決める）。
  大きい素因数に平方因子がある行は対象外（この pair は箱から除く。除いた数を報告する）。
  L ≤ 1 は決定的、L = 2 は G の全走査で厳密、L ≥ 3 はモンテカルロ（1 セル **1,000** 標本、種 20261005）。
- 各 p について、モデル化できる pair の集合 K_p、観測した成功数 S_p、モデルの期待値 E_p = Σ(1−P_i)、分散 V_p = Σ P_i(1−P_i)、
  全失敗確率 Z_p = ∏ P_i、成功数の分布（Poisson 二項、畳み込みで厳密）。

## 事前登録する仮説

- **H11-a（較正）**: Σ_p S_p / Σ_p E_p は 1 ± 0.01（H10' の再確認）。
- **H11-b（予測）**: pair 間が独立なら、分散比 R = Σ_p (S_p − E_p)² / Σ_p V_p ≈ 1。見立て（主張ではない）: R ∈ [0.9, 1.1]。
  R > 1.1 なら pair 間に正の相関（モデルの外の構造）がある。
- **H11-c（予測）**: 全 pair で失敗した素数の数 #{p : S_p = 0} は Σ_p Z_p に近い（Poisson 近似で ±2√(ΣZ_p) の範囲）。
  観測した全滅の素数それぞれについて Z_p を報告する。Z_p が小さい（< 0.01）全滅の素数があれば、「偶然では説明しにくい」として挙げる。
- **H11-d（測定）**: S_p のヒストグラムと、モデルの期待ヒストグラム Σ_p P(S_p = k) を並べる。
- **H11-e（機構の確認、測定）**: 同じ p の 2 つの pair が 7 より大きい奇素因数を共有する頻度。
  q が ap+u と a'p+u' を割れば q | a'u − au' ≤ 6·23 = 138 なので、138 より大きい素因数は共有できない。共有が稀なら独立の機構的な根拠になる。

## 成功・失敗の基準

- H11-a が外れたら実装の誤りとして報告する。
- H11-b / -c は予測の成否をそのまま書く。外れたら原因の候補を列挙する（範囲は広げない）。
- H11-d / -e は測定値を出す。

## 主張しないこと

存在補題（「全 pair で失敗する素数が無限に多いか」には答えない）、新しい族、Lean の定理。
帰無モデルは発見の道具で、定理ではない。
