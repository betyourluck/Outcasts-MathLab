# P1: 失敗の地図 — 事前登録の契約（2026-10-05、計算前に固定）

目的は反例探しではなく、**失敗した (p, a, u) の理由を分類すること**。数を大きくしない。

## 入力（固定）

- 素数 p < 1,000,000 で、p mod 840 ∈ {1, 121, 169, 289, 361, 529}（Mordell の平方類）。
- 較正用: 奇数 m（3 ≤ m ≤ 999）の平方数 n = m²。
- (a, u): 1 ≤ a, u ≤ 6、gcd(a, u) = 1（Dahan Lemma 3.10 により互いに素で足りる）。

## 各 (n, a, u) で記録するもの

- M = a n + u、その完全な素因数分解（試し割り、整数のみ）。
- m₀ = 4au。T = { q mod m₀ : q は M の奇素因数、gcd(q, m₀) = 1 }。
- D = M の奇数の約数の剰余集合 mod m₀（指数込みで全展開）。
- 成否: −1 ∈ D か（= 証人があるか）。照合として、M の約数を 1..√M の整数走査で列挙し、`s ≡ −1 (mod m₀)` を直接判定した結果と一致すること。
- 失敗のとき、次の 3 型に分類する（G = (ℤ/m₀)^×、G² = 平方元の部分群、⟨T⟩ = T の生成部分群）:
  - **QR 型**: −1 ∉ ⟨T⟩·G²（⇔ ある二次指標 χ で χ(−1) = −1 かつ T ⊂ ker χ）
  - **部分群型**: −1 ∈ ⟨T⟩·G² だが −1 ∉ ⟨T⟩
  - **指数型**: −1 ∈ ⟨T⟩ だが −1 ∉ D（有限の指数で届かない）
- QR 型のとき、特定の指標 ψ(q) = J(−au | q)（奇素数 q）で T ⊂ ker ψ か。

## 事前登録する仮説

- **H1（較正、平方数）**: n = m² ではすべての (a, u) が失敗し（Lean `no_witness_of_square` と整合）、
  失敗はすべて QR 型で、しかも T ⊂ ker ψ。
  根拠: q | a m² + u なら −au ≡ (am)² (mod q) なので J(−au | q) = 1。
- **H2（導出の検査、素数）**: p ≡ 1 (mod 8) で T ⊂ ker ψ となる失敗では、必ず J(u | p) = 1。
  根拠: q | ap+u なら J(−au|q) = J(p|q)·J(a²|q) = J(p|q) = J(q|p)（p ≡ 1 mod 4）。
  T ⊂ ker ψ なら M の奇数部分 M' について J(M'|p) = 1。M ≡ u (mod p) かつ J(2|p) = 1（p ≡ 1 mod 8）
  なので J(u|p) = 1。成立率 100% でなければ、導出か実装のどちらかが誤り。
- **H3（測定のみ、主張なし）**: 素数の失敗に占める QR 型・部分群型・指数型の割合。
- **H4（測定のみ、主張なし）**: 素数の QR 型の失敗で、障害の指標が ψ に限られるか、他の χ もあるか。

## 成功・失敗の基準

- 成功: 全行で二方式の成否が一致。H1・H2 は 100% の成立を予測、1 件でも外れたら報告して原因を調べる。
- H3・H4 は測定値を出すだけで、仮説として採否はつけない。
- 失敗は書き換えずに報告する。範囲は広げない。

## 主張しないこと

存在補題、新しい族、Lean の定理。この計算は有限の観察で、Lean では検証しない。
