# P1 / H10': 帰無モデルからの超過は小さい素因数で説明できるか — 事前登録の契約（2026-10-05、計算前に固定）

指数型の分類（`briefs/p1-exponent-contract.md`）の H10 で、平方因子を持たない行の失敗数が
帰無モデル（素因数の剰余を「積 = r の制約つき一様」とする）より 7.4% 多かった（ω ≥ 2、全 ω で同じ向き）。
候補の原因は、小さい素因数 q（3, 5, 7, …）の剰余 q mod m₀ が一様ではなく固定されていること。
これを検査する。範囲は広げない。

## 入力（固定）

- P1 の素数の行と H2' の行（計 125,610 行）のうち、M' が平方因子を持たない行（H10 と同じ 102,571 行）。
- 閾値 B で奇素因数を「小さい（q ≤ B）」と「大きい（q > B）」に分ける。**主たる B = 23**。感度の確認として B = 7 と B = 100。

## モデル H10'(B)

- 小さい素因数の剰余 F = (q mod m₀ : q ≤ B) は与件（固定）。
- 大きい素因数 L 個の剰余は、積が r' = r / ∏F になる制約のもとで一様（L−1 個を一様に取り、最後を r' で決める）。
- 失敗確率 = 「F と大きい素因数の全部分積のどれも −1 でない」確率。
  L ≤ 1 は決定的（観測と一致するはず。較正）。L = 2 は G を全走査して厳密に数える。L ≥ 3 はモンテカルロ（1 セル 300 標本、種 20261005）。
- 比較: 行ごとに P_model を出し、L ごと・ω ごとに Σ P_model と観測した失敗数を比べる。
  H10' の下では残る乱数が大きい素因数だけなので、行間の独立をおおむね仮定でき、分散 Σ P(1−P) から z 値を出す（独立の仮定は注記する）。

## 事前登録する仮説

- **H10'-a（較正、予測 100%）**: L ≤ 1 の行ではモデルが決定的で、観測と全件一致。
- **H10'-b（予測）**: H10（全部一様）のモデルで、ω ∈ {2, 3} の行を「B=23 以下の奇素因数を持つ / 持たない」で分けると、
  超過は**持つ側に集中**し、持たない側は観測/モデル ≈ 1。
- **H10'-c（予測）**: H10'(23) の L ≥ 2 の行で、観測/モデルは H10 の 1.074 より 1 に近づく。
  見立て（主張ではない）: |z| < 3 に収まる。収まらなければ、小さい素因数以外の構造がある。
- **H10'-d（感度、測定）**: B = 7, 23, 100 で、L ≥ 2 の行の観測/モデルを並べる。小さい素因数が原因なら B とともに 1 に近づく。

## 成功・失敗の基準

- H10'-a は 1 件でも外れたら実装の誤りとして報告する。
- H10'-b / -c は予測の成否をそのまま書く。外れたら「別の構造がある」と報告し、原因の候補を列挙する（範囲は広げない）。
- H10'-d は測定値を出す。

## 主張しないこと

存在補題、新しい族、Lean の定理。帰無モデルは発見のための道具で、「素因数の剰余は一様である」という定理ではない。
