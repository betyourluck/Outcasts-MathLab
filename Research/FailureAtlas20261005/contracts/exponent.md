# P1 / 指数型の分類 — 事前登録の契約（2026-10-05、計算前に固定）

P1・H2' で「指数型」と分類した失敗（−1 ∈ ⟨T⟩ だが、ap+u の実際の約数の剰余集合 D に −1 がない）の中身を分類する。
境界測量士が README で「finite-exponent obstructions」と呼んだものに当たる。範囲は広げない。

## 入力（固定）

- P1 の素数の行（`briefs/p1/failure_atlas_rows.json.gz` の `primes`、54,510 行）と H2' の行（`h2prime_rows.json.gz`、71,100 行）。
  平方数の行は全件 QR 型なので対象外。
- 各行で M = ap+u を再度素因数分解（試し割り）。M' = M の奇数部分、m₀ = 4au、G = (ℤ/m₀)^×、r = M' mod m₀。
  u ≤ 23 < p なので M の奇素因数はすべて m₀ と互いに素（検査で確認する）。

## 各行で記録するもの

- 全行: ω(M')（相異なる素因数の数）、Ω(M')、M' が平方因子を持たないか、r。
- 失敗行: T（素因数の剰余）、|T|、φ(m₀)、**対合の検査** T ∩ ι(T) = ∅（ι(x) = −x⁻¹、Dahan Lemma 4.2）、|⟨T⟩|、|D|、∏(vᵢ+1)。
- 指数型の行: **k_min** = 各素因数の指数を一律 k まで許したとき −1 に届く最小の k、max vᵢ、⟨T⟩ = G か、
  ω = 1 のときは q の位数 ord と、必要な指数 ord/2 と v の差。

## 事前登録する仮説

- **H6（較正、予測 100%）**: 失敗行（全型）はすべて T ∩ ι(T) = ∅ を満たす（Lemma 4.2 は定理なので外れたら実装の誤り）。したがって |T| ≤ φ(m₀)/2。
- **H7（較正、予測 100%）**: 指数型の行は k_min ≥ 2。ω = 1 の指数型は M' = q^v で、ord(q) は偶数、q^{ord/2} ≡ −1、v < ord/2。
- **H8（測定）**: 指数型の ω の分布を、全行・QR 型・成功行の ω の分布と比べる。平方因子を持たない割合も。
  見立て（主張ではない）: 指数型は小さい ω に偏る。
- **H9（測定）**: k_min の分布、⟨T⟩ = G の割合、|D| と ∏(vᵢ+1) の差（約数の剰余の重なり）。
- **H10（測定、帰無モデルとの比較）**: 平方因子を持たない行について、次の帰無モデルで失敗確率を計算する:
  t₁..t_{ω−1} を G から一様独立に取り、t_ω = r / ∏ t_i とする（積 = r の制約を保つので、二次指標の全体制約 χ(M') = χ(r) は自動で満たされる）。
  「どの部分積も −1 でない」確率 P_model を、ω ≤ 3 は厳密に数え、ω ≥ 4 はモンテカルロ（1 セル 300 標本、乱数の種 20261005）で求める。
  ω ごとに Σ P_model と観測した失敗数を比べ、比を報告する。閾値は置かない（測定のみ）。
  ω = 1 ではモデルは決定的（r ≠ −1 なら失敗）で、観測と一致するはず（較正）。

## 成功・失敗の基準

- H6・H7 は 1 件でも外れたら報告し、原因を調べる。
- H8〜H10 は測定値を出すだけで、採否はつけない。
- 失敗は書き換えずに報告する。範囲は広げない。
