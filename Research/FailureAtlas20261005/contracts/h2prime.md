# P1 / H2': 非剰余の u で ψ 型の失敗が消えるか — 事前登録の契約（2026-10-05、計算前に固定）

P1 の H2 は、840 の平方類では u ≤ 6 がすべて p の平方剰余だったため判別力がなかった。
J(u|p) = −1 となる u を入れて、同じ導出を判別できる形で検査する。範囲（p の集合）は P1 と同じで、広げない。

## 入力（固定）

- 素数 p < 1,000,000、p mod 840 ∈ {1, 121, 169, 289, 361, 529}（P1 と同じ 2,370 個）。
- u ∈ {11, 13, 17, 19, 23}、a ∈ {1, …, 6}（u は素数なので gcd(a,u) = 1）。
- 記録・分類は P1 と同じ（`briefs/p1/failure_atlas.py` の `analyze`。素因数分解と整数走査の二方式で成否を照合、
  失敗は QR / 部分群 / 指数の 3 型、ψ(q) = J(−au|q) による T ⊂ ker ψ の判定）。

## 事前登録する仮説

- **H2'（予測 100%）**: J(u|p) = −1 の行では、T ⊂ ker ψ となる失敗が 1 件もない。
  根拠（P1 の H2 と同じ導出）: q | ap+u なら J(−au|q) = J(p|q) = J(q|p)（p ≡ 1 mod 4）。
  T ⊂ ker ψ なら ap+u の奇数部分 M' で J(M'|p) = 1、ap+u ≡ u (mod p)、J(2|p) = 1（p ≡ 1 mod 8）なので J(u|p) = 1。
- **判別力の確認**: J(u|p) = −1 の行と J(u|p) = +1 の行がどちらも十分な数（各 1,000 行以上）あること。
  J(u|p) = +1 の行では ψ 型の失敗が実際に起きていること（起きていなければ、検査は依然として判別力がない）。
- **H5（測定のみ、主張なし）**: J(u|p) の符号ごとの失敗率と、失敗の型の内訳。

## 成功・失敗の基準

- 二方式の成否が全行で一致すること。
- H2' は 1 件でも ψ 型の失敗が J(u|p) = −1 の行に出たら、導出か実装の誤りとして報告して原因を調べる。
- H5 は測定値だけを出す。

## 主張しないこと

J(u|p) = −1 の (a,u) で証人が**ある**とは主張しない（ψ 以外の指標や、指数型・部分群型の失敗は残りうる）。
Lean の定理ではない（対応する補題は L2 で別に証明する）。
