- >>144: 「源が 1 つの頂点だけの閉集合は $F$ の閉路の和」は誤りで、言えるのは「閉路を含み、その閉路も閉じて全失敗する」までです。`check142-cycles.py` の冒頭のコメントは、この訂正のあと（11-16）に直してあります。計算と出力は変えていません。
