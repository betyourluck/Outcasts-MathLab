# 最も難しい素数: 最小の平方非剰余 n₂(p) と、箱の中で成功する組の数（H 検査）— 事前登録の契約（2026-10-10、計算前に固定）

（名前: 「H 検査」。判定を H0〜H2、測定を H3〜H6 とする。H11 などの既存の名前とは別物。）

## 動機

命題 N（PR #6 `witness_has_nonresidue_prime_factor`・`witness_prime_factor_nonsquare`）: 証人 s は、p を法とする平方非剰余の素因数を必ず持つ。
したがってその素因数は、p の最小の平方非剰余 n₂(p) 以上である。6 類の素数は 2・3・5・7 がすべて平方剰余（p ≡ 1 mod 8、p ≡ 1 mod 3、p ≡ ±1 mod 5、p mod 7 ∈ {1,2,4}）なので、
n₂(p) ≥ 11。n₂(p) が大きい素数ほど、証人に使える小さい素因数が少ない。そうした素数が「最も難しい素数」かを測る。

## すでに見ているもの（探索、`explore.py` → `explore_results.json`）

公開済みの X・Y・E・S・Q 検査の行（4·10⁶ < p < 1.3·10⁷、17,564 素数）で、n₂(p) と、互いに素な a·u ≤ ⌈log₂ p⌉ の箱で証人を持つ組の数 C(p) を比べた。

- 平均 C(p) は n₂ とともに減った: n₂ = 11 で 14.62（8,800 素数）、13 で 13.49、17 で 12.72、19 で 11.93、23 で 11.13、29 で 10.85、31 で 10.77、37 で 10.67、41 で 9.89（19 素数）。
- 順位相関（Spearman）は全体で −0.28、範囲ごとに −0.27 / −0.33 / −0.32 / −0.28 / −0.27。
- C(p) が下位 5%（C ≤ 5 パーセンタイル）の素数で、n₂ ≥ 17 のオッズ比は範囲ごとに 2.9 / 4.4 / 3.5 / 4.3 / 3.6。下位 1% では n₂ ≥ 17 が 61%（全体 24.6%）、n₂ ≥ 29 が 12%（全体 2.7%）。
- 形: 加重最小二乗で C ≈ 14.61 − 11.65 · S(n₂)、S(n₂) = Σ_{11 ≤ q < n₂, q 素数} 1/q が n₂ = 41 まで合った。
- ただし C = 3 の 3 素数（5843041、9744001、12197641）の n₂ は 11・13・17 で、n₂ だけでは難しさは決まらない。
- 以前の難しい素数の n₂: 345601 は 19、670849 は 17、3678481 は 23、8615161 は 17、53722321 は 31。

## 入力（固定、未使用の範囲）

- **1.3·10⁷ < p < 1.6·10⁷、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数**（どの既存の範囲とも重ならない。個数はまだ数えていない）。
- 箱: 互いに素な (a,u)、a·u ≤ ⌈log₂ p⌉（この範囲では 24）。C(p) = 証人を持つ組の数（小さい組も含む全組）。
- 成否は S・Q 検査と同じ（`../Simultaneity20261010/simultaneity_test.py` の `factor_all` と `judge`。試し割りは 20,000 までの素数、M < 3.84·10⁸ < 20,000² なので残りは 1 か素数。
  2 方式の一致、因数分解の積、種 20261022 で選んだ 1% の行の直接走査で照合し、食い違えば止める）。
- n₂(p): 奇素数 q を小さい順に、オイラーの規準 p^((q−1)/2) mod q で調べる（p ≡ 1 mod 4 なので (q | p) = (p | q)）。

## 判定（事前登録）

- **H0（命題 N の点検）**: 見つかったすべての証人 s が、(p | q) = −1 の素因数 q を持ち、そのうち最小のものが n₂(p) 以上。1 件でも外れれば計算の誤りとして止める（Lean の定理に反するため）。
- **H1（主: n₂ が大きいほど成功する組が少ない、予測）**: C(p) と n₂(p) の Spearman の順位相関 r < 0、正規近似 z = r·√(n − 1) の片側 p 値 < 0.001。
- **H2（最も難しい層への集中、予測）**: C(p) ≤ C の 5 パーセンタイル の素数で、n₂ ≥ 17 のオッズ比 ≥ 2、かつ Fisher の正確検定の片側 p 値 < 0.001。

## 測定（判定に使わない）

- **H3（減り方の形）**: n₂ ごとの平均 C と、探索の当てはめ（a = 14.61、κ = 11.65）の予測、新しい範囲で当てはめ直した a・κ。
- **H4（証人の非剰余の素因数）**: 成功した組の最小の証人について、その最小の非剰余の素因数 q*（≥ n₂）の分布。n₂ ≥ 29 の素数での q* の分布と、q* > 1000 の割合。
- **H5（最も難しい素数）**: C(p) の最小の 15 素数と、その n₂。
- **H6（どの組が救うか）**: n₂ ≥ 29 の素数で成功した組の a·u の分布を、n₂ = 11 の素数と並べる。

## 止める条件と上限

H0 の食い違い、2 方式の不一致、因数分解の積の不一致、直接走査との不一致で止める。1 プロセス、上限 120 分。範囲・箱・統計・種は変えない。

## 主張しないこと

存在補題、標本外の素数への保証。H1・H2 が成立しても、言えるのは「この範囲・この箱では、n₂(p) が大きい素数ほど成功する組が少なく、最も難しい層に集まる」まで。
n₂(p) は無限に大きくなりうる（Graham–Ringrose、孫引き）ので、点ごとの存在補題にとって n₂ の大きい素数がどう効くかは、この有限の観察からは言えない。
