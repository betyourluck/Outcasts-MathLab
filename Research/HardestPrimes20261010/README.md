# HardestPrimes20261010 — 最小の平方非剰余 n₂(p) と、箱の中で成功する組の数（H 検査）

有限計算です（使う命題 N は PR #6 で Lean 化済み）。命題 N から、証人は p を法とする平方非剰余の素因数を必ず持ち、その素因数は p の最小の平方非剰余 n₂(p) 以上です。
6 類の素数では 2・3・5・7 がすべて平方剰余なので n₂(p) ≥ 11 で、n₂(p) が大きいほど証人に使える小さい素因数が少なくなります。そうした素数が「最も難しい素数」かを測りました。

## 契約と順序

- 公開済みの X・Y・E・S・Q 検査の行（4·10⁶ < p < 1.3·10⁷、17,564 素数）で探索し（`explore.py` → `explore_results.json`）、見立てを立てました。
  探索の最初の版は n₂ の計算で q = 2 にオイラーの規準を当てて全素数で n₂ = 2 になる誤りがあり、奇素数だけを調べるよう直してから数値を見ています（直した版だけをコミット）。
- 契約 `contract.md` を、探索のスクリプト・結果と一緒に計算の前に fork へ push しました（コミット `24990a2`、2026-10-10T07:13:03Z）。
- 計算の直前に、H0 で確かめた証人の総数を記録する欄の書き損じ（常に None）を直しました。判定の式は変えていません。
- 確認の計算は 07:14:01Z〜07:14:22Z（21 秒）。止まらずに 1 回で終わりました。別のディレクトリでもう一度実行し、結果（所要時間を除く）と全行データが一致しました。

## 入力

1.3·10⁷ < p < 1.6·10⁷、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数 5,613 個（どの既存の範囲とも重ならない）。互いに素な (a,u)、a·u ≤ 24 で 376,071 行。
成否は S・Q 検査と同じ関数（2 方式、因数分解の積、1% の 3,631 行で直接走査）で全行一致しました。

## 判定

| | 結果 | 判定 |

| H0 すべての証人が、n₂(p) 以上の非剰余の素因数を持つ（命題 N の点検） | 証人 146,309 個（成功した 81,547 行）で違反 0 | 成立 |

| **H2 最も難しい層への集中** | C ≤ 9（5 パーセンタイル）の 374 素数で n₂ ≥ 17 のオッズ比 2.78、Fisher の片側 p ≈ 6·10⁻²⁰ | **成立** |

## 測定

- **H3（減り方の形）**: n₂ ごとの平均 C は 11: 15.38（2,823 素数）、13: 14.30、17: 13.58、19: 12.75、23: 12.50、29: 11.47、31: 11.51、37: 11.80（15 素数）、41: 9.25（4 素数）。
  C ≈ a − κ · Σ_{11 ≤ q < n₂} 1/q を当てはめ直すと κ = 11.03（探索は 11.65）、a = 15.36（探索は 14.61）。傾きは同じで、水準は約 0.75 上がりました
  （この範囲では全素数の予算が 24 で、探索の範囲より組の数が多いため、と読めます）。
- **H4（証人の非剰余の素因数）**: 成功した組の最小の証人について、その最小の非剰余の素因数 q* の分位（10・25・50・75・90%）は、全素数で 13・29・127・1,567・46,157、
  n₂ ≥ 29 の 136 素数で 37・61・227・1,700・23,180。q* > 1000 の割合は 28% と 31%。成功の約 3 割は、1000 を超える大きい非剰余の素因数に頼っています。
- **H5（最も難しい素数）**: C = 4 の 3 素数（13223281、15156289、15754201）の n₂ はいずれも 13。C = 5 には n₂ = 41・29・19・19・17・17・11・11・11 が並びます。
  n₂ は難しさの大きな要因ですが、それだけでは決まりません。
- **H6（どの組が救うか）**: 成功した組の a·u の内訳は、n₂ ≥ 29 の素数で a·u ≤ 3: 14%、4〜12: 45%、13〜24: 41%、n₂ = 11 の素数で 15%・45%・40%。ほとんど同じでした。

## 読み方（主張ではありません）

- n₂(p) が大きい素数ほど、箱の中で成功する組が少なく、最も難しい層に集まります。減り方は「11 以上の平方剰余の素数 q ごとに、1/q に比例して成功が減る」形で、
  Q 検査で見た仕組み（q が ap+u を割っても、p を法として剰余なら証人の非剰余の素因数として使えない）と合っています。
- それでも、n₂ ≥ 29 の素数でも平均 11 組以上が成功し、成功の約 3 割は 1000 を超える非剰余の素因数によるものでした。最も難しい素数の救済は、主に大きい素因数の側から来ています。
- 存在補題に向けては、n₂(p) が大きいことは「使える小さい素因数が減る」という形でしか効かず、点ごとに救うのは大きい非剰余の素因数です。
  n₂(p) は無限に大きくなりうる（Graham–Ringrose、孫引き）ので、点ごとの保証には、大きい非剰余の素因数が箱のどこかで −1 (mod 4au) に届くことを示す別の仕組みが要ります。

## 主張しないこと

存在補題、標本外の素数への保証。この範囲・この箱での観察です。
