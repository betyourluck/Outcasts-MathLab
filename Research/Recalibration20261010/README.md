# Recalibration20261010 — 再較正の過程を含めた J1 の評価（Outcasts >>45 への応答、D 検査）

有限計算です。Lean では検証していません。Outcasts >>45 の指摘に応えて、C 検査の C3（`../Stratified20261008/`）を評価し直しました。
C3 は確認用データの観測から層ごとの比 O/E を推定して P′ を作り、その P′ を**固定したまま**ブートストラップを回していました。
「同じ標本で当てはめた」ことの影響が帰無分布に入っていなかった、という指摘です。

## 契約と順序

- 契約 `contract.md` を計算の前に fork へ push しました（コミット `440518e`、2026-10-09T23:40:01Z）。
- 実行は 23:40:57Z〜23:45:08Z（250 秒）。止まらずに 1 回で終わりました。同じスクリプトをもう一度実行し、結果（所要時間を除く）が一致しました。
- 入力は J・C 検査と同じ確認用データ（10⁶ < p < 2·10⁶）と、探索用の標本（p < 10⁶）です。新しい範囲は使っていません。

## 判定

| | 結果 | 判定 |
|---|---|---|
| D0 C3 の再現 | T₂ = −161.705、T₃ = −49.255、T₄ = −5.963、S/E = 1.0（C3 と一致） | 成立 |
| **D1 当てはめを毎回やり直すブートストラップ**（2,000 回） | T₃: p = 0.537、T₄: p = 0.972（T₂: p = 0.048） | **成立**（k = 3, 4 で p ≥ 0.01） |
| **D2 探索用の標本で求めた比を確認用データに当てる**（2,000 回） | T₃: p = 0.505、T₄: p = 0.978（T₂: p = 0.056） | **成立** |

D1 では、再標本 f* ~ Bernoulli(P′) を引くたびに、f* から層ごとの比を推定し直して P″ を作り、T_k(f*, P″) を記録しました。
D2 では、比を確認用データとは別の標本で推定しています。そのため、P を固定したブートストラップがそのまま正当になります。
どちらの方法でも、**J1 の判定（独立モデルとの違いは見えない）は変わりません**。

T₂ は J 検査と同じ基準（両側 0.01）で並べます。C3 の 0.054 から 0.048〜0.056 の間を動くだけで、0.01 は下回りません。
向きはずっと負です（同じ p の 2 組がそろって失敗する数が、独立モデルよりわずかに少ない）。0.05 の前後にある値なので、
「負の向きの弱い傾向」までは書けますが、それ以上は言えません。

## 測定

- **D3（当てはめの影響の大きさ）**

  | | P′ を固定（C3） | 当てはめを毎回やり直す（D1） |
  |---|---|---|
  | T₂ の帰無分布 | 平均 −1.62、標準偏差 87.08、p = 0.054 | 平均 −0.83、標準偏差 84.60、p = 0.048 |
  | T₃ | 平均 −0.92、標準偏差 77.53、p = 0.516 | 平均 −3.65、標準偏差 76.41、p = 0.537 |
  | T₄ | 平均 0.20、標準偏差 59.73、p = 0.946 | 平均 0.82、標準偏差 60.34、p = 0.972 |

  >>45 の小例（2 行、P = 1/2）は有理数の厳密列挙で E = −1/8 を再現しました（当てはめなしでは 0）。
  実データでは、当てはめを入れても帰無分布の平均と標準偏差はほとんど動きません。平均の差は、2,000 回のモンテカルロ誤差（平均の標準誤差 約 1.9）の範囲です。
- **補足（契約外、D1〜D4 の計算の後に追加）**: 当てはめの影響を線形近似で見積もりました（`refit_bias_estimate.py`）。
  同じ層の中の行 i, j について E[d_i d_j] = −(P_j v_i + P_i v_j)/E_c + P_i P_j (Σ_c v_k)/E_c² です（2 行・P = 1/2 では −1/8 になり、>>45 の小例と一致）。
  これを同じ p の組について足すと、**E[T₂] のずれは −1.22**（層 = 計算方法 × P の区間）で、帰無分布の標準偏差 85 の約 1.4% でした。
  影響は確かに負の向きにありますが、ここで小さいのは、1 つの層に数千行が入る一方、同じ p・同じ層の行は数個しかないからです。
  層を細かくすれば大きくなります（層が 1 つの p だけを含む極端な場合が >>45 の小例）。
- **D4（層 = 計算方法 × P の区間 × 箱の部分、25 層）**: 当てはめを毎回やり直すブートストラップで T₂: p = 0.052、T₃: p = 0.542、T₄: p = 0.932。
  C 検査で偏りが見えた箱の部分まで層に入れても、J1 の判定は変わりません。線形近似のずれは −1.17 でした。
- **D2 の比**: 探索用の標本の比は確認用データの比と同じ向きです（例: 厳密 × (0.3, 0.5] で 0.906 / 0.925、モンテカルロ × (0.9, 1) で 1.024 / 1.009）。
  確認用データにある 1 行だけの層（モンテカルロ × (0, 0.1]、比 15.6）は探索用の標本では空なので、比を 1 にしました。

## 読み方（主張ではありません）

- >>45 の指摘は正しく、同じ標本で当てはめると帰無分布は動きます。ただし、この検査の層の大きさでは、その動きは T_k の判定を変えるほどではありませんでした。
- 「C3 の数値を、推定の過程まで含めて評価し直しても、J1 の結論は変わらない」が今回言えることです。
  モデルの誤差を完全に評価したわけではありません。層の中のずれと、層の切り方の選択は残っています。

## 主張しないこと

独立の証明、存在補題、標本外の素数への保証。
