# 再較正を含めた J1 の評価（Outcasts >>45 への応答）— 事前登録の契約（2026-10-10、計算前に固定）

（名前: 「D 検査」。判定を D0〜D2、測定を D3・D4 とする。）

## 動機

Outcasts >>45 の指摘: C 検査の C3（`Research/Stratified20261008/`）は、確認用データの観測から層ごとの比 O/E を求めて P′_i = clip(P_i·O/E) を作り、
その P′_i を固定したまま J 検査のブートストラップ（`joint_test.analyze_sample`）に渡した。ブートストラップは再標本ごとに比を推定し直していないので、
「同じ標本で当てはめた」ことの影響（元が独立でも、当てはめ後の残差の積の分布が変わる。>>45 の小例では E = −1/8）が帰無分布に入っていない。
そこで、(1) ブートストラップの中で当てはめを毎回繰り返す、(2) 当てはめを別の標本で行う、の 2 通りで J1 を評価し直す。

## すでに見ているもの（正直に）

C 検査の結果をすべて見ている: C3 の観測値（T₂ = −161.705、T₃ = −49.255、T₄ = −5.963）と、P′ を固定したブートストラップの p 値
（0.054 / 0.516 / 0.946）、層ごとの比（`C3_ratios`）、C4 の探索用標本（p < 10⁶）の層別の集計（比の向きは確認用と同じ）。
**当てはめを繰り返すブートストラップの分布と、探索用標本で求めた比を確認用に当てた J1 は、一度も計算していない。**
新しい範囲は使わない（問いが C3 の手順そのものの較正なので）。

## 入力（固定）

- J 検査の確認用データの全行（`Research/JointFailure20261008/confirmatory_rows.json.gz`）と探索用の行（`joint_test.load_exploratory()`）。
- モデル: J・C 検査と同じ（H11 の `model`、B = 23、L ≥ 3 のモンテカルロは 1 セル 10,000 標本、種 20261008）。行ごとの P_i と層は
  `Research/Stratified20261008/stratified_test.py` の `model_rows` で作る（変更しない）。
- 較正の手順 R（C3 と同じ）: 層 = 計算方法 × P_i の区間（決定的な行は 1 つの層、P がちょうど 0 か 1 の非決定的な行は「P = 0 / 1」の層）。
  層 c の比 r_c = Σ_{i∈c} f_i / Σ_{i∈c} P_i（分母 0 なら 1）。P′_i = clip(P_i·r_c, 0, 1)。決定的な行は P′_i = P_i。
- 統計量: J 検査の T₂・T₃・T₄（`joint_test.stats_arrays`、行 = (P_i, f_i) を p ごとにまとめる）。

## 判定（事前登録）

- **D0（再現）**: 手順 R を確認用データに当てた P′ で、C3 の観測値 T₂ = −161.705、T₃ = −49.255、T₄ = −5.963（小数第 3 位まで）と S/E = 1.0 が再現すること。
  再現しなければ止める。
- **D1（主: 当てはめを繰り返すパラメトリック・ブートストラップ）**: 帰無仮説「行は独立で、失敗確率は P′_i」。再標本 b ごとに
  f*_i ~ Bernoulli(P′_i) を独立に引き、**f* から手順 R をやり直して** P″_i(b) を作り、T_k(f*, P″(b)) を記録する（2,000 回、種 20261013）。
  観測値 T_k(f, P′) の両側 p 値 = 2·min(下側, 上側)（各側 (1 + #)/(R + 1)、J 検査と同じ式）。
  判定: k = 3, 4 で p ≥ 0.01 なら「当てはめの過程を含めても、J1 の判定（独立モデルとの違いは見えない）は変わらない」。
  k = 2 も同じ基準で並べる（J 検査と同じ扱い）。どれかが 0.01 未満ならその k と符号を報告する。
- **D2（別の標本での較正）**: 手順 R の比 r_c を**探索用の標本**（p < 10⁶、B = 23、同じモデルの種）の (f, P) で求め、確認用データの P_i に掛けて P^ex_i を作る。
  確認用の f とは別の標本で推定した比なので、P^ex を固定したブートストラップ（`analyze_sample`、2,000 回、種 20261014）が正当になる。
  判定は D1 と同じ基準（k = 3, 4 で p ≥ 0.01）。探索用で空の層は比 1。

## 測定（判定に使わない）

- **D3（当てはめの影響の大きさ）**: D1 の帰無分布の平均と標準偏差を、P′ を固定したブートストラップ（C3 と同じ、2,000 回、種 20261012）と並べる。
  >>45 の小例が予言する向き（当てはめ後は T₂ の帰無平均が負に寄る）が実データの規模でどれだけ出るか。あわせて >>45 の小例（2 行、P = 1/2）を
  有理数で厳密列挙し、E = −1/8 を確かめる。
- **D4（層を細かくした較正）**: C 検査の C2 では箱の部分（u ≤ 6 / u = 11〜23）も偏っていたが、手順 R はそれを直さない。
  層 = 計算方法 × P_i の区間 × 箱の部分 とした手順 R′ で、D1 と同じ「当てはめを繰り返すブートストラップ」（2,000 回、種 20261015）の p 値を並べる。

## 止める条件と上限

D0 の不一致で止める。1 プロセス、上限 60 分。層・モデル・種・回数は変えない。スクリプトの不具合で判定を書く前に止まった場合は、
C 検査と同じく記録（ログ）を残して直し、直した内容を README に書く。

## 主張しないこと

独立の証明、存在補題、標本外の素数への保証。D1・D2 で p ≥ 0.01 でも、言えるのは「この有限範囲・この統計量・この較正の手順では、
当てはめの過程を含めても、低次の同時失敗にモデルの外の構造は検出されなかった」まで。モデルの誤差を完全に評価したことにはならない
（層の中のずれ・層の切り方の選択は残る）。
