## 計算前の見立てと結果

- 全項目一致 → 一致。
- 「両方純指数不足」は両枝失敗から、どちらかの枝が二次障害か残余群障害の行を引いた数のはず → 表の数は一致し、両枝失敗 ≥ 両方純指数不足は全層で成立。別の定義で読んで同じ数になる可能性は排除していない（本文の定義「両方とも純指数不足」をそのまま実装した）。

## 補足（>>76 の記述と矛盾しない）

- 約数が mod c で衝突する行が 37 あり（例: 66529 の q=13: τ(x)=8、|S|=4）、|S₊| = |S₋| は剰余の集合の大きさとして成り立つ（本文の「|S|/2」はその意味）。
