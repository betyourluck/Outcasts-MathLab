## 1. 定義（相手の契約 `l8-norm-contract-20261017.md` と README から写し、自前で実装する）

p は 6 類（p ≡ 1,121,169,289,361,529 mod 840）の素数、組 (a,u) は互いに素、N = ap+u、m = 4au、φ = φ(m)、λ(m) = 8（L = 8）。
χ は m を法とする Dirichlet 指標、F_χ = ∏_{q^e ∥ N_odd} Σ_{j=0}^{e} χ(q)^j。W = #{d ∣ N : d ≡ −1 mod m}（実約数）。

- **R** = W_{G²}/|G²|（G² = 平方剰余類）。実指標だけから R = (1/φ) Σ_{χ 実} χ(−1) F_χ と計算し、約数の剰余の計数 W_{G²}/|G²| と一致することを assert する。
- **T₄** = Σ_{位数 4 の共役対の代表} χ(−1)(F_χ + F_χ̄)（正規化前の整数。F_χ ∈ Z[i]、F_χ + F_χ̄ = 2 Re F_χ）。
- **位数 8 の共役対の代表 χ** ごとに |F_χ|² = G + D√2 を Z[√2] の中で厳密に計算する。計算は Z[ζ₈] = Z[x]/(x⁴+1) で F_χ · F_χ̄ を作り、剰余が [G, D, 0, −D] の形（√2 = ζ₈ − ζ₈³）であることを assert する。相手の局所公式 |S(h,e)|² = (e+1) + 2Σ_{j=1}^{e}(e+1−j)cos(πhj/4) = g + d√2 は、別経路（cos の値 {1, −1, 0, ±√2/2} の表）で g, d を作って積と一致することを確かめる。さらに浮動小数で |F_χ|² を直接計算し、G + D√2 と 10⁻⁶ 以内で一致することを確かめる。
- **U** = G + (3/2)D（D ≥ 0）、G + (7/5)D（D < 0）。7/5 < √2 < 3/2 なので U ≥ |F_χ|²。
- **ρ_χ** = ⌈1024√U⌉/1024（整数の平方比較で切り上げ、浮動小数を使わない）。ρ_χ² ≥ U を assert する。
- **raw** = R + (T₄ − 2 Σ_{位数 8 の代表} ρ_χ)/φ、**c_mag** = max(0, raw)。
- **c_old** = (W − η)₊（η = C − Σℓ/φ、>>57 の規約、10-15 の自前実装 `chars20261015.py` の `row()` と同じ）。
- **非剰余の重複度** = Σ_{q^e ∥ N, (q∣p) = −1} e。**K** = ⟨q mod m : q ∣ N, q 奇⟩、目標 m−1 ∈ K。
- 健全性の根拠（相手の導出を自分で追う）: W = R + (T₄ + Σ_{位数 8 の代表} χ(−1)(F_χ + F_χ̄))/φ（直交性）、χ(−1)(F_χ + F_χ̄) = ±2 Re F_χ ≥ −2|F_χ| ≥ −2ρ_χ。全行で整数の恒等式 φW − φR − T₄ = Σ_{位数 8} χ(−1)(F_χ + F_χ̄) を assert する。
