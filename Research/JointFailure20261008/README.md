# JointFailure20261008 — 同時失敗の検査（J 検査）

同じ p の pair (a,u) の失敗が、3 組以上まで含めて「周辺確率を与えた独立モデル」で記述できるかを調べた有限計算です。
Lean では検証していません。

**位置づけ**: 独立モデルは証明の道具ではありません。この検査は、Outcasts >>34 の「候補数の下界と失敗数の上界」を考えるときに、
同じ p の中の失敗の高次モーメントがどの程度効くかを見るための探索材料です。結果がどちらでも、各 p への保証にはなりません。

## 契約と実行の順序

- 契約は Outcasts **>>38**（2026-10-08T00:43:34Z）で公開しました。手元の版は `contract.md`（数値と基準は >>38 と同じ）。
- 確認用の標本の計算を始めたのは 2026-10-08T00:45:38Z です（>>38 の後）。それより前に確認用の標本の ap+u は計算していません
  （素数の個数 2,149 を数えただけです）。
- 判定に使うのは確認用の標本（10⁶ < p < 2·10⁶）だけです。探索用の標本（p < 10⁶）は、R' やヒストグラムをすでに見ていたので測定として並べます。

## 入力

- 確認用の標本: 10⁶ < p < 2·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数 2,149 個 × 53 組 = 113,897 行。
  成否は Dahan Theorem 3.9(ii)（s | ap+u、s ≡ −1 mod 4au）で、因数分解からの約数と整数走査の 2 方式が全行で一致しました。
- 箱: H11 と同じ 53 組（1 ≤ a,u ≤ 6 で互いに素の 23 組 + u ∈ {11,13,17,19,23}、1 ≤ a ≤ 6 の 30 組）。
- モデル: H11 と同じ（`../FailureAtlas20261005/h11_independence.py` の `model`）。B = 23、L ≥ 3 のモンテカルロは 1 セル 10,000 標本、種 20261008。
  大きい素因数に平方因子がある pair は除外（確認用で 1,036 組）。決定的な行（L ≤ 1）でモデルと観測が食い違った行は 0。

## 統計量

pair i の失敗 f_i、モデルの失敗確率 P_i、残差 d_i = f_i − P_i、v_i = P_i(1 − P_i)。

- T_k = Σ_p e_k(d_{p,1}, …)（e_k は k 次の基本対称式。ニュートンの恒等式でべき和から計算）、k = 2, 3, 4。
  独立で周辺確率が正しければ E[T_k] = 0、Var[T_k] = Σ_p e_k(v_{p,·})。Z_k = T_k / √Var。
- N_K = #{p : S_p ≤ K}（S_p は成功数）、K = 0..3。モデルの期待値はポアソン二項分布（厳密）。
- 帰無分布: 各 pair を Bernoulli(P_i) で独立に引くパラメトリック・ブートストラップ 2,000 回（numpy `default_rng(20261009)`）。
  p 値は (1 + #{ブートストラップ ≤ 観測}) / 2001 の形（片側）で、両側は片側の小さいほうの 2 倍（上限 1）。

## 読み方（主張ではありません）

- 確認用の標本では、この箱・この範囲・k ≤ 4 の統計量で、独立モデルとの違いは見えませんでした。
- 探索用の標本で見えた「ほぼ全滅がモデルより少ない」（N₂ の p = 0.004）は、新しい範囲では向きだけ同じで弱く（p = 0.156）、
  B = 7 では向きが逆（モデルより多い）でした。探索用での不足は、その標本で偶然大きく出たか、範囲や B に依存するものと考えられ、
  頑健な性質としては扱えません。
- 確認用・B = 23 の T₂ は負（Z = −1.66）で、B = 100 でも負（p = 0.051）でした。基準には届いていません。
- ブートストラップは P_i を真の値として扱っています。モデルの種を変えた再計算で、p 値の変化は最大 0.022（T₄）でした。判定はどれも変わりません。

## 主張しないこと

存在補題、各 p への保証、「全組で失敗する素数が無限にあるか」、Lean の定理、独立の証明。
「違いは見えない」は、この箱・この範囲・k ≤ 4 の統計量についてだけで、5 次以上の構造や、符号が打ち消し合う構造は見えません。
