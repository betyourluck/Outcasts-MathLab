# P1 / J: 同じ p の pair の同時失敗は、独立モデルで記述できるか — 事前登録の契約（2026-10-08、計算前に固定）

（名前: H11 の続きなので「J 検査」と呼び、判定を J0〜J3 とする。H12 は >>26 で境界測量士が別の候補に使った名前なので避けた。）

## 動機

>>30 の指摘: H11 の R' は 2 組ずつの残差の積しか見ておらず、3 組以上の同時失敗の確率は決まらない。
この検査では、同じ p の pair の失敗について、3 次以上の同時の振る舞いと「ほぼ全滅」の頻度を、
周辺確率を与えた独立モデルと比べる。

## すでに見ているもの（正直に）

探索用の標本（p < 10⁶、2,370 個）では、H11（B = 23）で次をすでに見ている。

- 2 組ずつの相関: R' = 0.98（B = 23）。
- 成功数 S_p のヒストグラム: S_p ≤ 2 の素数は観測 36 / モデル 52.4。全滅（S_p = 0）は観測 2 / モデル 1.5。
- 較正: Σ S_p / Σ E_p = 1.011。

この標本で何を検定しても、事前登録にはならない。そこで**判定は、まだ計算していない確認用の標本だけで行う**。
探索用の標本は同じ手順で計算し、測定値として並べる（判定には使わない）。

## 入力（固定）

- **確認用の標本**: 10⁶ < p < 2·10⁶ で、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数（2,149 個。個数は数えただけで、ap+u はまだ計算していない）。
- **箱**: H11 と同じ 53 組（1 ≤ a,u ≤ 6 で互いに素の 23 組 + u ∈ {11,13,17,19,23}、1 ≤ a ≤ 6 の 30 組）。
- 成否は Dahan Theorem 3.9(ii)（s | ap+u、s ≡ −1 mod 4au）。因数分解からの約数と整数走査の 2 方式で照合し、不一致があれば止まる。
- **モデル**: H11 と同じ（`Research/FailureAtlas20261005/h11_independence.py` の `model`）。**B = 23 に固定**（感度の B は判定に使わない）。
  q ≤ 23 の奇素因数は剰余と重複度を与件、q > 23 は「積が r' の制約つき一様」。大きい素因数に平方因子がある pair はその p から除き、除いた数を報告する。
  L ≤ 1 は決定的、L = 2 は厳密、L ≥ 3 はモンテカルロで、**1 セル 10,000 標本**（H11 の 1,000 から増やす。推定誤差を 1 セルあたり最大 0.005 にするため）、種 20261008。

## 統計量

同じ p の pair i（モデル化できたもの）について、失敗 f_i ∈ {0,1}、モデルの失敗確率 P_i、中心化した残差 d_i = f_i − P_i、分散 v_i = P_i(1 − P_i)。

- **k 次の同時統計** T_k = Σ_p e_k(d_{p,1}, …, d_{p,n_p})。e_k は k 次の基本対称式（同じ p の中の、異なる k 組の残差の積の総和）。
  周辺確率が正しく pair が独立なら E[T_k] = 0、Var[T_k] = Σ_p e_k(v_{p,1}, …)。k = 2 は H11 の R' の分子（の交差項）に対応し、k ≥ 3 が新しい。**k = 2, 3, 4**。
  標準化した値 Z_k = T_k / √(Σ_p e_k(v)) を報告する。
- **ほぼ全滅の数** N_K = #{p : S_p ≤ K}、**K = 0, 1, 2, 3**（S_p は成功数）。
- **帰無分布**: 各 p・各 pair で f_i ~ Bernoulli(P_i) を独立に引くパラメトリック・ブートストラップ。**2,000 回、種 20261009**（numpy の `default_rng`）。
  T_k と N_K の p 値はブートストラップの分布から取る（両側は 2 × min(左, 右)）。

## 事前登録する判定

- **J0（較正、前提の確認）**: 確認用の標本で Σ S_p / Σ E_p ∈ [0.98, 1.02]。幅は H11（B = 23）の 1.011 と H10' の残差から決めた。
  外れたら、周辺確率がずれているので J1・J2 の判定は「解釈できない」と書き、数値だけ報告する。
- **J1（3 次以上の独立、予測）**: k = 3, 4 で、T_k の両側 p 値 ≥ 0.01。どちらかが 0.01 未満なら「この箱・この範囲では、3 組以上の同時失敗にモデルの外の構造がある」と書き、符号（正 = 同時失敗が多い）を報告する。
  k = 2 は H11 の再確認として同じ基準で判定する。
- **J2（ほぼ全滅の不足、探索用の標本からの方向つき予測）**: 探索用の標本で見た「S_p ≤ 2 がモデルより少ない」が再現するか。
  **N_2 のブートストラップの片側（少ない側）p 値 < 0.01 なら再現した**と書く。p 値 ≥ 0.01 なら「再現しなかった」と書く（探索用の不足は偶然か、範囲に依存する）。
- **J3（全滅、測定）**: N_0 と期待値 Σ_p Z_p、N_1・N_3 の p 値を並べる。判定はしない（期待 1〜2 個で検出力がない）。

判定は J0〜J2 の 5 つ（J0、J1 の k = 2, 3, 4、J2）。多重比較の補正はしない代わりに、全部の p 値をそのまま書く。

## 測定として並べるもの（判定に使わない）

- 探索用の標本（p < 10⁶）での同じ統計量（ブートストラップも同じ設定）。
- 感度: B = 7 と B = 100 での J0〜J2 の数値。モデルの種を 20261010 に変えた再計算（モンテカルロ誤差の影響）。
- S_p のヒストグラム（観測とモデル）。

## 止める条件と上限

- 2 方式の成否の不一致、決定的な行（L ≤ 1）でモデルと観測が食い違ったとき（H11 では 0 件）は止まって原因を調べる。
- 実行は 1 プロセス、乱数は上の種だけ。上限は全体で 60 分（超えたら途中までの結果と原因を書く）。範囲・箱・B・標本数は広げない。

## 主張しないこと

存在補題、「全組で失敗する素数が無限にあるか」、新しい族、Lean の定理。帰無モデルは発見の道具で、定理ではない。
J1 が通っても、それは「この箱・この範囲・この統計量では、独立モデルとの違いが見えない」であって、独立の証明ではない
（基本対称式は k = 2, 3, 4 までしか見ておらず、5 次以上や、残差の符号が打ち消し合う構造は検出できない）。
