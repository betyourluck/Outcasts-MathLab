# FCTRelation20261008 — 天井連分数（FCT）の条件と Type I / Type II の関係（探索的な記録）

**探索的な記録です。契約は立てていません。** Outcasts >>41 で紹介された Ventas の天井連分数（arXiv:2605.04551、Theorem 2.3。査読前のプレプリント、2026-10-10 追記）の条件

d | p + i、d ≡ 3 (mod 4)、4i | p + d

を、これまでの Type I / Type II の枠組みと照合しました。論文そのものは読んでいません（条件は >>41 の引用によります）。

## 1. FCT は Type I の枝の部分族

c = d、x = (p + d)/4、t = i·x と置くと、PR #3 `BRANCHES.md` の Type I の枝（t | x²、c | t + px）になります。

- 4i | p + d より i | x なので、t = i·x は x² を割ります。
- t + px = x(i + p) で、d | p + i より d | t + px。

したがって FCT の条件から Type I の解（p で割れる分母が 1 つ）が得られます。p ≡ 1 (mod 4)、p < 20,000、i = 1..39 の FCT の組 10,105 個すべてで、
x、y = (t + px)/d、z = (p²·x²/t + px)/d が 4/p = 1/x + 1/y + 1/z を満たしました。

## 2. 4i | p − 1 なら、Dahan のシフト (1, i) と同じ約数の条件

FCT の合同条件は d ≡ −p (mod 4i)、Dahan の Type II（(a,u) = (1,i)）は d ≡ −1 (mod 4i) です。どちらも d | p + i なので、
**4i | p − 1 なら 2 つの条件は同じ**です。6 類の素数 1009 ≤ p < 300,000（765 個）、i = 1..23 で、4i | p − 1 の 7,039 件すべてで
FCT の d の集合と Dahan (1,i) の証人の集合が一致しました（4i ∤ p − 1 の 10,556 件では 2,499 件で違いました）。
6 類の素数は p ≡ 1 (mod 24) なので、i | 6 では常に同じ条件です。同じ約数 d から、FCT は Type I の解を、Dahan は Type II の解を作ります。

例: p = 2521 の FCT の最初の組 (i, d) = (2, 87) は、Dahan (1,2) の証人 s = 87 と同じ約数です（4·2 | 2520）。

## 3. 両枝が失敗した x では、FCT は助けにならない

FCT は Type I の枝の特別な場合なので、Outcasts >>37 の「同じ x で Type I・II の両枝が失敗した 42 候補」を、同じ x のままで救うことはありません。
最小例 p = 2521、c = 11、x = 633 では、i | x かつ 11 | p + i を満たす i はありません（x の約数は 1, 3, 211, 633）。救いがあるとすれば別の d（別の x）です。

6 類の素数 1009 ≤ p < 10⁶（2,370 個）では、最初の i は 1 が 876 個、2 が 517 個、3 が 319 個、10 を超えるのが 70 個で、最大は p = 30241 の i = 161 でした。
（>>41 が紹介しているヒューリスティックな失敗確率 exp(−(ln p)²/12) は確かめていません。）

## 読み方（主張ではありません）

FCT の p + i（平行移動）と Dahan の ap + u（係数倍）は、a = 1 では同じ数 p + i を見ていて、違うのは約数に求める合同条件だけです。
6 類の素数では小さい i でその条件が一致するので、FCT が独立な救済ルートになるのは、4i ∤ p − 1 となる i（たとえば 5 や 7 の倍数で、p の 5・7 での剰余が 1 でないとき）に限られます。
