# 小さい組の全滅と、広げた組の失敗の同時性（S 検査）— 事前登録の契約（2026-10-10、計算前に固定）

（名前: 「S 検査」。判定を S0〜S3、測定を S4〜S7 とする。）

## 動機

`../SmallShifts20261008/` で、6 類の素数では a·u ≤ 3 の 5 組（(1,1)、(1,2)、(2,1)、(1,3)、(3,1)）に、全体の符号が必ず +1 の奇な指標が残ることを見た。
5 組がすべて失敗する素数は約 6〜7% ある。存在補題の形としては「小さい組の失敗が、a·u を広げた組の失敗と同時には続かない」ことを評価したい
（`../WitnessProgram20261008/` §4、Outcasts >>45 の「指標の障害と実約数の残存を各 p で同時に」）。
そこで、小さい 5 組の全滅（F_S）と、広げた組（a·u ≥ 4）の失敗との依存を測り、依存があるならその原因を特定する。

## すでに見ているもの（探索、`explore.py` → `explore_results.json`）

公開済みの X・Y・E 検査の行（4·10⁶ < p < 7·10⁶、5,963 素数、広げた組 345,088 行）で、次を見た。

- F_S の素数は 414 個（6.9%）。広げた組の失敗の Mantel–Haenszel オッズ比（層 = 組）は **1.042**（素数単位のブートストラップ 2,000 回、95% 区間 1.006〜1.082）。
  弱い正の依存。範囲ごとには 1.048 / 1.058 / 1.016 で、どれも単独では 95% 区間が 1 を含む。
- **p mod 11 を層に加えると依存が消えた**: オッズ比 0.993（0.958〜1.031）、変化 Δ₁₁ = log OR(層なし) − log OR(p mod 11) = **0.048**（0.038〜0.058）。
  範囲ごとの Δ₁₁ も 0.041 / 0.060 / 0.042（どれも片側 p ≈ 0.002）。対照の Δ は 13: 0.006、17: 0.011、19: −0.001、23: −0.009。
- 見立て（初等的）: 6 類では p mod 3・5・7 が固定され、小さい組の成否を分ける素因数の最初の候補が 11 になる。11 ≡ 3 (mod 4)・11 ≡ −1 (mod 12) なので、
  11 | p+1 なら s = 11 が (1,1) の、11 | p+3 なら (1,3) の、11 | 3p+1 なら (3,1) の証人になる。p ≡ 10, 8, 7 (mod 11) の素数では F_S が 0 件だった。
  同じ 11 が広げた組の ap+u を割るかどうかも p mod 11 で決まるので、両者が p mod 11 を通じてつながる。
- p mod 16、p mod (5, 7)、p mod 13・17・19・23 の単独の層では依存は消えなかった。23 も 5 組すべての証人になりうる剰余類（≡ 3 mod 4、≡ 7 mod 8、≡ 11 mod 12）だが、Δ は −0.009。
- F_S の素数でも広げた組の成功は最低 3 組、平均 10.8 組（他の素数は 11.1 組）。

## 入力（固定、未使用の範囲）

- **7·10⁶ < p < 10⁷、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数**（どの既存の範囲とも重ならない。個数はまだ数えていない）。
- 箱: 互いに素な (a,u)、a·u ≤ ⌈log₂ p⌉（PR #4 WitnessBudget と同じ規約。この範囲では 23 か 24）。小さい組 = 上の 5 組、広げた組 = 残り（a·u ≥ 4）。
- 成否: ap+u の約数 s で s ≡ −1 (mod 4au) があるか。因数分解（16,000 までの素数で試し割り。M < 2.56·10⁸ なので残りは 1 か素数）から、
  (1) 剰余集合の積み上げ と (2) 全約数の列挙 の 2 方式で判定し、全行で一致しなければ止める。因数分解の積が M に戻ることも全行で確かめる。
  さらに種 20261020 で選んだ 1% の行で、M の平方根までの直接走査とも照合する。

## 統計（`simul_stats.py`、探索と同じコード）

- 曝露 = F_S(p)、結果 = 広げた組の失敗。Mantel–Haenszel オッズ比。層なし = 層は組だけ、p mod q で層別 = 層は (組, p mod q)。
- Δ_q = log OR(層なし) − log OR(p mod q で層別)。不確かさは素数単位のブートストラップ（2,000 回、種 20261020）。同じ再標本で全統計量を計算する。
- 片側 p 値 = (1 + #{再標本の値 ≤ 0}) / (2,000 + 1)。

## 判定（事前登録）

- **S0（初等的な確認）**: p ≡ 10, 8, 7 (mod 11) の素数では、それぞれ (1,1)、(1,3)、(3,1) で s = 11 が証人になり、F_S は 0 件。
  1 件でも食い違えば計算の誤りとして止める。
- **S1（主: p mod 11 が依存を担う、予測）**: Δ₁₁ > 0 で、片側 p 値 < 0.01。
- **S2（層別後の残り、予測）**: p mod 11 で層別したオッズ比の 95% 区間が 1 を含む（層別後の依存は検出されない）。
  検出力は高くないので、成立しても「残りの依存がない」とは書かず、「検出されなかった」と書く。
- **S3（11 の特異性、予測）**: Δ₁₁ − max(Δ₁₃, Δ₁₇, Δ₁₉, Δ₂₃) > 0 で、同じ再標本での片側 p 値 < 0.01。

S1〜S3 は探索で立てた見立ての方向つきの予測。多重比較の補正はしない代わりに、すべての値をそのまま書く。

## 測定（判定に使わない）

- **S4**: 層なしのオッズ比と 95% 区間（探索では 1.042）。
- **S5**: p mod 11 の剰余ごとの F_S の割合と広げた組の失敗率。
- **S6（救済）**: F_S の素数での広げた組の成功数の最小と平均。箱の中に証人が 1 つもない素数の数（PR #4 の 1 億までの検査と同じ箱なので、0 の再確認）。
- **S7**: 曝露を小さい組 1 つずつの失敗にしたときのオッズ比（層なし / p mod 11 で層別）。

## 止める条件と上限

S0 の食い違い、2 方式の不一致、因数分解の積の不一致、直接走査との不一致で止める。1 プロセス、上限 120 分。範囲・箱・統計・種は変えない。
スクリプトの不具合で判定を書く前に止まった場合は、記録（ログ）を残して直し、直した内容を README に書く。

## 主張しないこと

存在補題、独立の証明、標本外の素数への保証。S1〜S3 が成立しても、言えるのは「この範囲・この箱では、小さい組の全滅と広げた組の失敗の弱い依存は
p mod 11 で説明でき、それを除くと検出されない」まで。p が大きくなったとき、あるいは箱の予算を変えたときのふるまいは見ていない。
