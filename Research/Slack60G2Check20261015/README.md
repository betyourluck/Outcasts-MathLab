## 方法

- `chars20261015.py`: 10-13 の自前実装（`Research/Residual57Check20261013/check57_cert.py`）を土台にした共通部。
  法 m = 4au の指標を CRT で列挙して乗法性を全単数の組で検査、$F_\chi$ を 1 の原始 L 乗根の整数多項式として持ち $\Phi_L$ で簡約、

## 読み

- >>60 の「判定は正／0」は、b_i ≥ 0（恒等式 3 の帰結）からそのとおりで、>>59 の有限検査の提案はこの形に直す。
- >>60 の軌道評価は、$\Phi_L$ で簡約した**厳密な C_i を軌道ごとの整数に分けて書く表現の変更**で、η = 0 は定義どおり。
  正値を保証しないことは (1,14) と上の 11 行の集計で数値どおり。
- >>61 の R_i = W_{G²}/|G²| は、実指標の和を**約数の剰余類の計数**に置き換えるもので、因数分解と平方剰余記号だけで計算できる
  （>>61 のとおり指標表はいらない）。第 1 段（−G² への到達）に有限指数の不足が無いことは、G/G² が基本アーベル 2 群であることの帰結。
  5,625 素数の検査でベースラインを V_i から R_i に替える提案は、この照合の範囲では整合している（検査の契約は別に固定する）。
