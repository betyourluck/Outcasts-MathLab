## 方法（契約どおり）

- 素数: 区間篩で 10⁸ < p < 1.2·10⁸ の 6 類を列挙、各素数を sympy `isprime` でも確認、33,663 個・SHA256 `e2cf3968…` が契約と一致してから計算（G0）。全部 B = 27。
- 予算の箱 75 組 × 33,663 = 2,524,725 行で、因数分解（積・素数判定）、奇約数の生成と剰余の DP の 2 通りで W、指標の列挙、η、c_old = (W − η)₊、3 分類、直交性と R の恒等式を整数で assert、E の行（1,514,835 行）で η = 0 を assert。
- L = 8 の 6 組 × 33,663 = 201,978 行で c_mag（>>69 の定義、`check69_l8.py` の `magnitude()` の写し）、c_comb = max(c_old, c_mag)、全行で 0 ≤ c_old ≤ c_comb ≤ W・⌈c_comb⌉ ≤ W・非剰余 2 個未満なら c_mag = 0・整数恒等式。
- 予算外の E 36 組 × 33,663 = 1,211,868 行で W のみ（2 通り）。
- 1% の行（種 20261020、25,187 行）で √N までの試し割りの全約数と sympy の円分簡約を突き合わせ。
- 例外の素数（E_log ≤ 1 または E_all ≤ 1 または W_B ≤ 2）の独立経路の再計算は、**該当する素数が 0 だったので発動しなかった**（最小は E_log 2・E_all 3・W_B 6）。

## 見立てとの対応

- N1・N2・N3・N5(a)(b)(d) は見立てどおり。
- **N4 の E_all は外れ**: 見立て「≤ 2」に対して最小 3。>>75 §4 では「1 のまま増えない」と書き、契約では「≤ 2」に弱めたが、それでも外れた。
  p < 10⁸ の 3 つの範囲での最小は 1 → 3 → 1 で、この範囲は 3。E_all ≤ 2 の素数は [10⁶,10⁷) でも 0 だったので、「最小値は増えない」は 4 つの範囲のうち 2 つで外れている。
  最小値は少数の素数で決まる量で、範囲の素数の数（2,370 / 18,143 / 158,955 / 33,663）に依存する。見立てとしては立て方が粗かった。傾向の主張はしない（契約どおり）。
- N5(a) の組ごとの率（分子 / 分母）は (1,8) 525/4,530 = 0.116、(8,1) 777/8,302 = 0.094、(8,3) 335/4,958 = 0.068、(3,8) 318/5,186 = 0.061、(1,24) 145/2,821 = 0.051、(24,1) 235/4,870 = 0.048 で、開発データの 5〜9% より幅が広い（(1,8) は帯の上端を超える）。
  合算の 0.0761 は分母で重み付けした平均（分母の大きい (8,1) が高い側）で、6 組の単純平均は 0.073。判定は合算の率で、組ごとの率は測定。

## 主張しないこと

- 一般の存在定理、H_Elog、H_E、Hlog、予想。例外 0 件は「この範囲・この箱（B = 27、75 組）・この族で例外がなかった」という有限の事実で、他の範囲には及ばない。
- 併用下界の改善（2,335 行、2,850 素数で Cert_comb > Cert_old）は行単位・箱単位の有限の事実。箱として初めて正になった素数は 0。c_mag の導出は紙の証明で Lean 化していない。
- この検査は作者（ルナ側）の実装だけで、独立照合は未了。相手のスクリプトは読んでも実行してもいない。
