# N8 検査 — 未使用の範囲 10⁸ < p < 1.2·10⁸ での事前登録検査（契約、計算前に固定、2026-10-20）

>>75 §4（こちらの案 (a)）、>>78・>>79（案 (b) の取り下げ）、**>>80**（境界測量士、2026-10-20 00:08Z: (a) に異論なし、契約に入れる区別 3 点）を受けて書いた契約。
マスターの了承を得て fork に push し、スクリプト `n8scan.py` を別のコミットで push してから、集団（33,663 素数）の計算をする。

## 位置付け

- 範囲 10⁸ < p < 1.2·10⁸ は、PR #4 >>20 以来の 179,468 素数（p < 10⁸）、K・G 検査（1.6〜1.9·10⁷）、有限検査 J〜S（≤ 1.6·10⁷）のどれにも使っていない。
  **候補命題と下界の限界を調べる事前登録の検査**であり、既知の範囲での予想そのものの反例走査とは区別する（>>13、>>80）。
- 例外が 0 件でも、普遍命題（H_Elog・H_E・Hlog）は何も証明されない。**例外は 1 個で候補を棄却する**。割合の帯はこの集団の記述にすぎない。
- Type I と可変予算は除かない（>>69 の「A・B を二択に固定しない」）が、この検査は Type II の証人（Dahan Thm 3.9 / Lemma 4.2 の判定条件 s ∣ ap+u、s ≡ −1 (mod 4au)）だけを数える。

## >>80 の 3 点をどう入れたか

1. **予算 B = 27 で一定**（2²⁶ < 10⁸ < 1.2·10⁸ < 2²⁷）。組の集合は >>80 の表のとおり（こちらでも数え直して一致）:
   予算内の互いに素な組 **75**、うち E **45**、λ(4au) = 8 **6**（(1,8),(8,1),(1,24),(3,8),(8,3),(24,1)）、E ∪ L8 **51**、その他 24。
   予算の外の E は 36 組（E 全体 81）。λ = 8 の組は全体で 18（au ∈ {8,24,40,120}、E と素で合わせて 99）だが、
   予算外の L=8 の 12 組はこの検査では計算しない（併用下界は予算の箱の中だけで定義する）。
   **51 組で証明書が 0 でも 75 組に証人がないとは限らない**ので、W_B（75 組の実証人の総和）を別に数える。
   この一区間では p の増加とともに予算が広がる効果は観測しない。
2. **各結果が何を反証するかを計算前に分ける**（§判定と §分岐）。H_Elog の反証の再発見と、未反証の H_E・Hlog の検査を同じ結論にまとめない。
3. **改善率の分母と下界の健全性を固定する**（§記号の c_comb、§判定 N5）。c_mag は >>69 の定義のまま変更しない。
   L = 8 では max(c_old, c_mag)、それ以外は c_old。判定は有理数のまま「> 0」で行い、整数化は ⌈·⌉ で報告のみ（健全性 ⌈c_comb⌉ ≤ W は全行で assert）。
   救出率の分母は「旧 0 行のうち W > 0」と「旧 0 行の全部（W = 0 含む）」の 2 つを別に報告し、行単位の救出と箱単位（素数）の救出も分ける。
   全行で 0 ≤ c_old ≤ c_comb ≤ W を assert し、例外では独立経路（全約数の試し割り・各因数の素数判定・sympy の円分簡約）で照合し、n₂(p) と B を記録する。

## 記号

- 組: a,u ≥ 1、gcd(a,u) = 1、k = au、m = 4k、φ = φ(m)、L = λ(m)、N = ap+u、B = ⌈log₂p⌉ = `(p−1).bit_length()` = 27。
- E = {k : λ(4k) ∈ {1,2,3,4,6}} = {k : k ∣ 60 または k ∣ 126}（20 個、81 組、>>65）。予算内 45 組、予算外 36 組。
- W_i = #{s ∣ N : s ≡ −1 (mod m)}（実約数、実指数）。W_{G²,i}、R_i = W_{G²,i}/|G²|、η_i = C_i − Σℓ_ij/φ ≥ 0、**c_old,i = (W_i − η_i)₊**（>>57・>>60・>>61、G 検査と同じ）。
- **c_mag,i**（L = 8 の行のみ、>>69 の定義そのまま、`Research/L8Magnitude69Check20261018/contract.md` §1 の自前実装の写し）:
  位数 4 の共役対の和 T₄、位数 8 の共役対ごとに |F_χ|² = G + D√2 を Z[√2] で厳密に計算、U = G + (3/2)D（D ≥ 0）/ G + (7/5)D（D < 0）、
  ρ_χ = ⌈1024√U⌉/1024（整数の平方比較）、raw = R + (T₄ − 2Σρ_χ)/φ、c_mag = max(0, raw)。健全性 0 ≤ c_mag ≤ W は >>69 の紙の導出（こちらで追った）。
- **c_comb,i = max(c_old,i, c_mag,i)**（L = 8）、= c_old,i（それ以外）。
- 素数ごと（予算の箱 = 75 組）: **W_B = Σ W_i**、S = #{W_i > 0}、Cert_old = Σ c_old,i = Cert_E + Cert_{0∖E} + Cert₊（G 検査の分解）、**Cert_comb = Σ c_comb,i**、
  E_log = Cert_E = Σ_{k∈E, k≤27} W_i、E_all = E_log + Σ_{k∈E, k>27} W_i。
- n₂(p) = p の最小の平方非剰余（奇素数を小さい順にオイラーの規準で。6 類では ≥ 11）。
- 失敗行の 3 分類（>>62）: 二次障害 / 群障害 / 有限指数不足（G 検査と同じ）。

## すでに見ているもの（正直に）

- この範囲の素数では**何も計算していない**。素数の列挙とハッシュだけを取った（下）。
- 自己検査（計算前、範囲外、`selftest.log`・`selftest_results.json`）: 固定 11 入力の L=8 の 42 行と開発データ 300 行（G 範囲）を 10-18 の自前の行データ
  `check69_rows.json.gz` と突き合わせ、38296729 の箱（73 組・E の 81 組）を 10-16・10-18 の値と突き合わせ、1.2·10⁸ 以上の 6 類の最初の 50 素数で時間を測った。
  50 素数の結果は時間の見積もりにだけ使い、判定の見立てには使っていない（見立ては G 検査・>>66 の走査・>>69 の開発データから）。
- 参考値: G 範囲（5,625 素数）で E_log の最小 2、E_all の最小 2、Cert_old > 0 が全部。p < 10⁸（179,468 素数）で H_Elog の例外は 38,296,729 の 1 個、H_E の例外 0、
  E_all の最小は範囲ごとに 1 → 3 → 1。開発データ（G 範囲の W > 0・c_old = 0 の L=8 の 4,709 行）で c_mag > 0 は 355（7.5%、組ごとに 5〜9%）。

  類ごとに 5,612 / 5,579 / 5,600 / 5,586 / 5,625 / 5,661、全部 B = 27。1 行 1 つ（LF、末尾も LF）の昇順リストの SHA256 =

## 行ごとの計算

- 予算の箱の全行: N の因数分解（積が N に戻る・各因数の素数判定）、奇約数の生成と剰余の DP の 2 通りで W_i、W_{G²}、K・KH の閉包、3 分類、
  法 m の指標の列挙、共役対の ℓ_ij・η_i・c_old,i。直交性 φW = Σχ(−1)F_χ と R_i の恒等式を整数で assert。E の行では η_i = 0 を assert。
- L = 8 の行（6 組 × 33,663 = 201,978 行）: さらに c_mag（|F_χ|² を Z[ζ₈] の積・cos の表の Z[√2] の積・浮動小数の 3 経路で一致、ρ² ≥ U、
  整数恒等式 φW − φR − T₄ = Σ_{位数 8} χ(−1)(F_χ+F̄_χ)、√2 の係数の総和 0、0 ≤ c_mag ≤ W、非剰余の重複度 < 2 なら c_mag = 0、(u∣p) = 1、
  各証人 s で (s∣p) = (N/s∣p) = −1、重複度は偶数で W > 0 なら ≥ 2）。c_comb と、0 ≤ c_old ≤ c_comb ≤ W・⌈c_comb⌉ ≤ W。
- 1% の行（種 20261020）: √N までの試し割りの全約数 = 因数からの生成、円分簡約 = sympy の多項式の割り算。
- 予算外の E の行: W_i のみ（2 通り）。
- **例外の素数（E_log ≤ 1、または E_all ≤ 1、または W_B ≤ 2）**: 111 行すべてを独立経路（試し割りの全約数・sympy の円分簡約）で計算し直し、
  行ごとの W と素数ごとの Cert_old・Cert_comb・E_log・E_all が一致することを assert する。
- 素数ごとに n₂(p) と B を記録する。

## 止める条件（G0）と上限

- 素数の個数・ハッシュが違う / スクリプトのコミットと作業ツリーが違う → 計算の前に止める。
- 因数の積が N に戻らない、W の 2 通りが食い違う、直交性・R の恒等式・L=8 の整数恒等式が崩れる、E の行で η ≠ 0、c_mag の 3 経路が食い違う、
  ρ² < U、c_mag > W、c_old > c_comb、c_comb > W、非剰余 2 個未満で c_mag > 0、|G²| 奇数の第 2 段失敗に群障害（>>62 の補題）、
  1% の行や例外の素数で試し割り・sympy と食い違う → その行で止めて記録する。
- 1 プロセス、上限 4 時間。見積もりは自己検査の実測（`selftest_results.json` の `timing`）から: 1 素数あたり 0.08 秒 × 33,663 ≈ 44（例外の素数の独立経路 0.8 秒/素数を含めて 45〜60） 分。
- 範囲・組・種・帯・見立ては変えない。スクリプトの不具合で判定を書く前に止まった場合は、ログを残して直し、直した内容を README に書く（failures #20 の型）。
