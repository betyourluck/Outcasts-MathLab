# P1 / X: 二次指標の障害は「全体の符号 + 小さい素因数 + 公平な硬貨」で記述できるか — 事前登録の契約（2026-10-08、計算前に固定）

（名前: 「X 検査」。判定を X1〜X3、測定を X4〜X6 とする。）

## 動機

失敗の型の分類（`Research/ObstructionTypes20261008/`）で、素因数の多い候補でも失敗の半分以上が二次指標の障害（QR 型）だった。
QR 型は、負の d | 2au について、ap+u の「使える」素因数 q（4au と互いに素）がすべて (d | q) = 1 になるときに起きる。
存在補題の (B)(i) に向けて、この障害がどの程度「全体の制約」で決まり、どの程度「偶然」なのかを分ける。

## 記号

行 (p, a, u)、m = 4au、使える素因数 q とその指数 e。負の平方因子なしの d（d = −d′、d′ | 2au）ごとに、

- s_d(q) = (d | q)（Kronecker 記号、q は奇素数）
- 全体の符号 G_d = ∏ s_d(q)^e = (d | ap+u の使える部分)
- 障害 Obs_d = 「すべての使える q で s_d(q) = 1」

境目 T を決めて、使える素因数を小（q ≤ T）と大（q > T）に分ける。**硬貨モデル**: 小さい素因数の符号は与件、大きい素因数の符号は
「積が G_d（を小さい素因数の分で割ったもの）になる条件のもとで、独立な公平な硬貨」。指数が偶数の大きい素因数は積に効かないので、
P(Obs_d) = [小さい符号がすべて +1]·[G_d = +1]·2^(−#偶数指数)·2^(−(#奇数指数 − 1))（大きい素因数がないときは決定的）。
(行, d) の組ごとに P を出し、観測した障害の数 O と期待値 E = Σ P、分散 Σ P(1−P) から z を作る（(行, d) を独立とみなす近似。同じ行の d どうしは相関しうる）。

## すでに見ているもの（正直に）

M 検査の範囲（3·10⁶ < p < 4·10⁶、公開済み）で、計算前に次を見た: 障害なのに G_d ≠ +1 の例 0。O/E は T = 23 で 0.973（z −23.0）、
T = 100 で 0.991（z −9.4）、T = 1000 で 0.9997（z −0.8）。大きい素因数が 2 個以上の組で、T = 23 の O/E は 0.94（2 個）、0.83（3 個）。
障害の 96% は、1000 より大きい使える素因数が 1 個以下の行で起きた。**判定は、まだ計算していない新しい範囲だけで行う。**

## 入力（固定）

- 素数: 4·10⁶ < p < 5·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529}（2,001 個。個数を数えただけ）。どの既存の範囲とも重ならない。
- 箱: 互いに素な (a,u)、a·u ≤ ⌈log₂ p⌉（この範囲では 22 または 23）。R・M 検査と同じ規約。
- 因数分解は試し割り。約数の 2 方式の照合は、成否（証人の有無）についてだけ行う（M 検査と同じ）。

## 判定（事前登録）

- **X1（理屈の確認）**: Obs_d なのに G_d ≠ +1 の (行, d) は 0 件。1 件でもあれば実装の誤りとして止める。
- **X2（主、予測）**: T = 1000 の硬貨モデルで O/E ∈ [0.98, 1.02] かつ |z| < 3。成り立てば「1000 以下の素因数と全体の符号を与件にすれば、
  残りの符号は公平な硬貨で記述できる」、成り立たなければ「できない」と書く。
- **X3（方向、予測）**: T = 23 の硬貨モデルで O/E < 1 かつ z < −3（障害が硬貨モデルより少ない）。成り立てば「23〜1000 の素因数の符号に偏りがある」の再現。

## 測定（判定に使わない）

- **X4**: T = 100 での O/E と z。T = 23 と T = 1000 での、大きい素因数の数ごとの O/E。
- **X5**: 障害（Obs_d）のうち、1000 より大きい使える素因数が 1 個以下の行で起きた割合。
- **X6**: d ごとの、障害の数と G_d = +1 の割合（上位 15 個の d）。

## 止める条件と上限

X1 の違反、成否の 2 方式の不一致で止める。1 プロセス、乱数なし、上限 60 分。範囲・箱・T は広げない。

## 主張しないこと

存在補題、(B)(i) の証明。硬貨モデルは発見の道具で、定理ではない。X2 が成り立っても、23〜1000 の素因数の符号の偏りがどこから来るか
（たとえば q | ap+u のとき (−au | q) = (p | q) となる PR #6 L2 の関係）は、この検査では説明しない。
