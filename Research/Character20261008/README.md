# Character20261008 — 二次指標の障害は「全体の符号 + 小さい素因数 + 公平な硬貨」で記述できるか（X 検査）

有限計算です。Lean では検証していません。失敗の型の分類（`../ObstructionTypes20261008/`）で主な障害だった二次指標の障害（QR 型）が、
どの程度「全体の制約」で決まり、どの程度「偶然」なのかを分けました。存在補題の (B)(i) に向けた材料です。

## 契約と順序

- 契約 `contract.md` を計算の前に fork へ push しました（コミット `58fb041`、2026-10-08T09:01:47Z ごろ）。
- 最初の実行（09:02:12Z）は、契約の止める条件（約数の 2 方式の不一致）で止まりました（`failed-run-1.log`）。原因は実装の誤りで、
  試し割りの素数表を 10,000 未満で打ち切っていたため、22·4716961 + 1 = 103,773,143 = 10039·10337 を素数と取り違えていました
  （この範囲の ap+u の平方根は最大 10,723）。素数表を 20,000 まで広げて 09:02:45Z に再実行しました（17 秒）。判定はまだ計算していませんでした。
  R・M 検査の範囲では平方根が最大 8,124・9,380 なので、この誤りは影響しません。
- 別のディレクトリで同じスクリプトをもう一度実行し、結果（所要時間を除く）と全行データが一致しました。

## 入力

4·10⁶ < p < 5·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数 2,001 個（どの既存の範囲とも重ならない）。互いに素な (a,u)、
a·u ≤ ⌈log₂ p⌉（22 または 23）で 125,297 行。成否の約数は 2 方式で全行一致。

## モデル

行と、負の平方因子なしの d（−d | 2au）の組ごとに、使える素因数 q（4au と互いに素）の符号 s_d(q) = (d | q)、全体の符号 G_d = ∏ s_d(q)^e、
障害 = 「すべての q で s_d(q) = 1」。境目 T 以下の素因数の符号は与件、それより大きい素因数の符号は「積が G_d に合う条件のもとで独立な公平な硬貨」
として障害の確率 P を出し、観測した障害の数 O を期待値 E = Σ P と比べます（z は (行, d) を独立とみなす近似）。

| X3 T = 23 で O/E < 1、z < −3 | O/E = 0.9726、z = −22.53 | 成立 |

## 測定

- **X4**: T = 100 で O/E = 0.9906、z = −9.90。大きい素因数の数ごとの O/E（T = 23）: 1 個 0.9997、2 個 0.938、3 個 0.823、4 個 0.708。T = 1000 では 1 個 1.000、2 個 0.993。
- **X5**: 障害の 95.9% は、1000 より大きい使える素因数が 1 個以下の行で起きた。
- **X6**: d ごとの障害の数と G_d = +1 の割合（上位）。

  | d | 障害 | G_d = +1 の割合 |
  |---|---|---|
  | −2 | 24,984 | 0.468 |
  | −1 | 20,138 | 0.508 |
  | −6 | 14,818 | 0.583 |
  | −3 | 11,969 | 0.500 |
  | −5 | 10,128 | 0.714 |
  | −14 | 7,644 | 0.700 |
  | −10 | 7,462 | 0.646 |
  | −21 | 4,826 | **1.000** |
  | −15 | 4,452 | **1.000** |

  d = −21 と −15 では、全体の符号が全組で +1 でした。p が 840 の平方類にあることから強制される、Mordell 型の全体の制約がそのまま見えています。

## 読み方（主張ではありません）

- 二次指標の障害は、「全体の符号（p の剰余と (a,u) で決まる部分を含む）」と「1000 以下の素因数の符号」を与件にすれば、
  残りの大きい素因数の符号を公平な硬貨としたモデルで、この範囲では記述できました。
- 23〜1000 の素因数の符号には偏りがあり（硬貨より障害が少ない）、その原因はこの検査では説明していません。候補は、q | ap+u のとき
  (−au | q) = (p | q) となる関係（PR #6 の L2）です。
- 障害の 96% は、大きい素因数が 1 個以下の行（「小さい素因数 × 大きい素数 1 つ」）で起きています。存在補題の (B)(i) は、
  「大きい素因数を 2 個以上持つ候補が十分ある」ことと「全体の符号が +1 に強制されない d の組がある」ことに分けて考えられそうです。

## 主張しないこと

存在補題、(B)(i) の証明。硬貨モデルは発見の道具で、定理ではありません。
