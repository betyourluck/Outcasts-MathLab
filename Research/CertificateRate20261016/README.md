# G 検査 — 証人を入力しない証明書の再解析・実装監査（K 範囲 5,625 素数、2026-10-16）

Outcasts スレッド `80c02e64` の >>63（契約案 v1）・>>64（ParallaxSol: 位置付けと分岐の質問）・>>65（境界測量士: 族 E、H_Elog・H_E、5 分岐）
を受けた有限検査。契約は `contract.md`（計算前に push、コミット `91a9835`）、スクリプトは計算前に別のコミットで push（`735e305`）。

**位置付け: K 検査（`Research/MainTermRatio20261012/`）で使った 5,625 素数の、事前仕様を固定した再解析・実装監査。
新しい標本での独立確認ではない。一般の存在定理・H_Elog・H_E・Hlog・予想には何も加えない。**

## 方法

- `gtest.py`（土台は 10-15 の自前実装 `chars20261015.py`、`6f20c00` の blob と同一）。
  - 素数を自分で生成し、昇順リストの SHA256 が契約の `e3cb7f64…` と一致することを確かめてから計算（G0）。
    実行時の HEAD（`735e305`）と、このディレクトリの追跡ファイルが HEAD と同じことも確かめた。
  - 予算の箱（au ≤ B、385,189 行）と、予算外の E の組（au ∈ {30,42,60,63,126}、202,500 行）。
  - 約数: 素因数分解（積・素数判定）から奇約数を生成して割り切りと個数を確かめる / 剰余の DP、の 2 通りで W_i。
    1% の行（種 20261016）で √N までの試し割りと、円分簡約の sympy との突き合わせ。
  - 指標: 予算の箱の全行で法 m の指標を列挙し、共役対の ℓ_ij・η_i・c_i = (W_i − η_i)₊。直交性と R_i の恒等式を整数で assert。
    E の行では全共役対が定数・η_i = 0 を assert（紙の上の導出の全行での確認）。
  - 群: W_{G²,i}、K = ⟨奇素因数⟩・KH = ⟨G², 奇素因数⟩ の閉包、3 分類（>>62）、コセットごとの約数の個数（(1,14) 型）。
  - 素数ごとの W_tot・S・組の数を K 検査の `mainterm_test_rows.json.gz` と照合。
- 自己検査（契約の前、集団の外）: 探索用の 10 入力で `ExactFamily65Check20261016` の 10 箱 × 14 項目、
  `Slack60G2Check20261015` の 3 分類 566/458/7/101・一様コセット 81 と全項目一致（`selftest.log`、`selftest_results.json`）。
- 実行: `python -I gtest.py cohort`（1 プロセス）。
- 実行時間 173.9 秒（契約の見積もり 5〜15 分、上限 3 時間）。exit 0。G0 はすべて通過（素数リストのハッシュ、HEAD `735e305`、
  素数ごとの W_tot・S・組の数が K 検査と 5,625 個すべて一致、予算内の E の 253,125 行すべてで η = 0、1% の 3,902 行で試し割りと sympy が一致）。

## 見立てとの対応

- G1・G2・GE は見立て（全部 / 0 個 / 0 個）どおり。>>59 の「半分に届かない」は 10-15 に計算前に撤回済みで、この結果はその撤回と整合する。
- G3 の二次障害の割合は 10 入力（難しい素数として選ばれた入力）の 0.809 より低い 0.763 で、帯 [0.75, 0.87] の下端寄りに入った。
  群障害の割合も 0.065 → 0.045 と低い。10 入力は失敗の多い素数に偏っているので、向きは自然だが、帯の幅を 10 入力から決めたことは記録しておく。

## 主張しないこと

- **これは公開済みの集団の再解析で、独立な標本での確認ではない。** H_Elog・H_E は K 範囲の 5,625 素数で例外がなかったという有限の事実で、
  他の範囲・一般の p には及ばない。予想・Hlog・Type II の存在にも何も加えない。
- E の行で η = 0 になることは紙の上の導出（λ(4k) ∈ {1,2,3,4,6} ⇒ Φ_L の次数 ≤ 2）によるもので、253,125 行での確認は実装の確認。
- Cert₊ > 0 の素数が 810 あっても、G2 が 0 なのは「その素数には緩み 0 の組の証人もある」という意味で、緩みのある組が不要だという主張ではない。
