## 記号

- 組: a,u ≥ 1、gcd(a,u) = 1。k = au、m = 4k、φ = φ(m)、L = λ(m)、N = ap+u、B = ⌈log₂p⌉ = `(p−1).bit_length()`。
- **E = {k : λ(4k) ∈ {1,2,3,4,6}} = {k : k ∣ 60 または k ∣ 126}**（20 個、81 組。>>65 の導出、こちらでも導いて確認）。
  E の組では、どの因数分解でも全共役対が Φ_L 簡約後に定数で η = 0、c = W。B ∈ {24,25} では予算内の E の組は 45 組、予算の外は 36 組。
- W_i = #{s ∣ N : s ≡ −1 (mod m)}。W_{G²,i}、R_i = W_{G²,i}/|G²|、η_i = C_i − Σℓ_ij/φ ≥ 0、**c_i = (W_i − η_i)₊**（v1 と同じ、>>57・>>60・>>61 の規約）。
- p ごと（予算の箱の中）:
  - Cert = Σ c_i = **Cert_E + Cert_{0∖E} + Cert₊**
  - Cert_E = Σ_{k∈E} W_i、Cert_{0∖E} = Σ_{k∉E, η_i=0} W_i、Cert₊ = Σ_{η_i>0} c_i、Cert₀ = Cert_E + Cert_{0∖E}
  - E_log = Cert_E（予算内の E の証人の数）、E_all = E_log + Σ_{k∈E, k>B} W_i（81 組全体）
- 失敗行（W_i = 0）の 3 分類（>>62）: 二次障害（W_{G²,i} = 0）／群障害（W_{G²,i} > 0 で −1 ∉ K、K = ⟨奇素因数⟩）／有限指数不足（−1 ∈ K で W_i = 0）。

## 行ごとの計算

- 全行（予算の箱、385,189 行）: N を因数分解（積が N に戻ること・各因数の素数判定）、奇約数を生成し 2 通りで W_i を数える（上の「v2 からの変更」）。
  W_{G²,i}、R_i、K = ⟨q : q ∣ N_odd⟩ の閉包と −1 ∈ K、KH = ⟨G², {q}⟩ の閉包、|G²| の偶奇、コセットごとの約数の個数（(1,14) 型）、3 分類。
- 全行（予算の箱）: 法 m の指標を列挙し、共役対の ℓ_ij、η_i、c_i。直交性 φW_i = Σχ(−1)F_χ と φW_{G²,i} = |G²|·Σ_{χ²=1}χ(−1)F_χ を
  整数で assert。E の行（k ∈ E）では λ(m) ∈ {1,2,3,4,6}、全共役対が定数、η_i = 0 を assert（紙の上の導出の全行での確認）。
- 1% の行（種 20261016、行の順に乱数を引く）: √N までの試し割りの全約数 = 素因数からの生成、円分簡約 = sympy の多項式の割り算。
- 予算外の E の行（202,500 行）: W_i のみ（2 通り）。

## 見立て（計算前に固定）

- G1: Cert(p) > 0 の p は **全部**（帯は ≥ 99%）。根拠: 探索用の 10 入力（難しい素数として選ばれたもの）がすべて予算内の E の証人を持ち、
  K 範囲の W_tot は最小 3、平均 26.5。H_Elog が成り立てば Cert ≥ Cert_E > 0。
- G2: Cert₀ = 0 かつ Cert₊ > 0 の p は **0 個**（帯は ≤ 1%）。
- GE: H_Elog の例外（E_log = 0）は **0 個**、H_E の例外（E_all = 0）は **0 個**。
- G3: 失敗行のうち二次障害は 10 入力の 80.9% の近く（帯 [0.75, 0.87]）、群障害は第 2 段の 10% 以下（10 入力では 7/108 = 6.5%）。

## 判定（事前登録）

- **G1**: Cert(p) > 0 となる p の割合 ≥ 0.99。Cert(p) = 0 の p は全部列挙する。
- **G2**: Cert₀(p) = 0 かつ Cert₊(p) > 0 となる p の割合 ≤ 0.01。該当する p は全部列挙する（行ごとの W_i・η_i・c_i）。
- **GE**: H_Elog の例外の数と H_E の例外の数（どちらも 0 が見立て）。例外の p は全部列挙する（E_log、E_all、Cert_{0∖E}、Cert₊、W_tot）。
- **G3**: 失敗行の 3 分類が上の帯に入るか。あわせて第 2 段のうち (1,14) 型の割合（10 入力では 75%）と、
  |G²| が奇数の第 2 段失敗がすべて有限指数不足であること（>>62 の補題）を全行で確かめる。

**割合の帯は、この再利用した集団の記述にすぎない。存在の候補（H_Elog・H_E・緩み 0 の組だけで覆う候補）は 1 個の例外で棄却される。**
G1 ≥ 99%・G2 ≤ 1% が成り立っても、例外の p を「解決済み」や「無関係」とは扱わない。

## 結果ごとの次の一手（>>64 への答え。計算前に固定）

| 観測 | 棄却されるもの | 次に探すもの |
|---|---|---|
| **D1** Cert(p) = 0 の p がある（W_tot ≥ 3 は既知なので、証明書がすべての証人を取りこぼした） | この箱での「共役対ごとの L1 下界」の普遍性（G1 が未達ならこれ） | 取りこぼした行で η を作る共役対を調べる。完全な軌道で束ねれば W は正確に戻る（>>60 §3）が、それは数え直しで存在の理由ではない。実際の指数上限を守った部分的な束ね方で、証人を入力しない下界を改良する |
| **D2** W_tot(p) = 0 の p がある | — （K 検査で W_tot ≥ 3 が分かっているので、出れば実装の不一致） | G0 で止めて原因を探す。Hlog の反例とは扱わない |
| **D3** Cert₀ = 0 かつ Cert₊ > 0 の p が 1 個でもある | 「予算内の緩み 0 の組だけで覆う」強めた候補（G2 の帯の中でも棄却） | 証明の経路に η > 0 の組を残す。その p で証人を持つ組の L と非定数の共役対を記録する |
| **D4** H_Elog の例外がある | H_Elog | (a) E_all > 0 なら H_E は残る → 次の命題は「予算によらない有限族 E（au ≤ 126）」の形に変える。(b) Cert_{0∖E} > 0 なら、因数に依存する有理性（E の外で η = 0）を扱う補題が要る。(c) Cert₊ だけなら (D3) と同じ |
| **D5** H_E の例外がある | H_E（有限族 E だけでは覆えない） | E の外へ出る。どの組（L、因数に依存する η = 0 か、η > 0 か）が救うかを記録する |
| **D6** 例外がない（全部成立） | 何も証明されない（有限の再解析） | 次の補題は「各 p で、E の組（予算内）のどれかの ap+u が s ≡ −1 (mod 4au) の約数を持つ」点ごとの存在。E は有限族だが約数は可変なので、多項式被覆の既知の障害（Elsholtz–Tao）は直ちには当たらない（>>65）。E_log の小さい p（下位 20）で、E の組がどの段で失敗しているかを手がかりにする |
| **D7** G3 が帯から外れる | 普遍命題は何も棄却しない（割合のずれは算術の矛盾ではない） | 二次障害が多い → 動く (a,u) で平方コセットが同時に全部外れることを点ごとに排除する補題。群障害が多い → 2 冪の非二次条件と H の位数が偶数の場合を残す補題。有限指数不足が多い → 実際の指数上限を守った因数ブロックの積で目標に届く補題 |

D1〜D5 は互いに排他ではない。該当するものをすべて報告する。

## 再現と止める条件（G0）

- 素数リストのハッシュが違う / スクリプトのコミットと blob が一致しない → 計算の前に止める。
- 因数の積が N に戻らない、W_i の 2 通りの数え方が食い違う、直交性や R_i の恒等式が崩れる、E の行で η ≠ 0、
  W_{G²,i} > 0 ⇔ −1 ∈ KH が崩れる、|G²| 奇数の第 2 段失敗に群障害が出る（>>62 の補題）、1% の行で試し割りや sympy と食い違う → その行で止める。
- 素数ごとの W_tot・S・組の数が K 検査の `mainterm_test_rows.json.gz` と 1 個でも違う → 止める。

## 主張しないこと
