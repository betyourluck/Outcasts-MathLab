## 1. 定義（>>96 の本文と README から写し、自前で実装する）

- p = 2521。素数であること、p mod 840 が 6 類 {1, 121, 169, 289, 361, 529} に入ることを確かめる。χ(a) = (a∣p) はオイラー基準 a^{(p−1)/2} mod p。
- 頂点集合 V = {q < p : q は素数、χ(q) = −1}。素数表はエラトステネスの篩と試し割りの 2 通りで一致させる。最小の非剰余 ℓ も求める。
- 頂点 q の源: σ(q) = 1（q ≡ 3 mod 4）/ 3（それ以外）、σ(q)qτ² < 3p を満たす正の奇数 τ すべて。c = σ(q)qτ²、x = (p + c)/4（整数であること、0 < x < p を assert する）。
- 源の成功: d ∣ x² のどれかで、Type II は c ∣ d + x、Type I は c ∣ d + px。判定は 3 通りで行い、源ごとに一致を assert する。
  - (i) x を試し割りで素因数分解し、指数の組から x² の約数を全部作る
  - (ii) 1 ≤ d ≤ x を走査して x² mod d = 0 の d と相方 x²/d を集める（因数分解を使わない）
  - (iii) 元の条件: (px)² の約数 D のどれかで c ∣ D + px（4/p − 1/x = c/(px) を 2 つの単位分数に分ける条件）。gcd(c, p) = 1 と gcd(c, x) = 1 を assert したうえで、(i) の判定と一致することを確かめる
- 頂点の成功: 源のどれかが成功。成功頂点の集合を S とする。
- 辺 q → r: q の源のどれかの x を割る素数 r で χ(r) = −1 のもの（指数に依らない）。r < p は x < p から出るが assert する。自己ループがないことも確かめる。
- 距離 D(q) = q から S までの有向辺の最短の本数（q ∈ S なら 0、届かなければ ∞）。2 通りで計算して一致を assert する: (a) S から逆向きの辺をたどる多始点 BFS、(b) 各頂点から順向きの BFS を 187 回。
- U₁ の反例頂点: 完全失敗（q ∉ S）で、どの出辺の先も S に入らない頂点。D(q) ≥ 2 または D(q) = ∞ と同じになることを確かめる。
