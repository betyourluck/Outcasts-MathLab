# SmallShifts20261008 — a·u ≤ 3 の組では、Mordell の障害がちょうど 1 つの指標として残る（探索的な記録）

**探索的な記録です。契約は立てていません。** 下の導出は初等的な合同計算で、データは公開済みの E 検査の行（`../Exponent20261008/`、
6·10⁶ < p < 7·10⁶ の 1,977 素数）との照合に使っただけです。新しい ap+u は計算していません。

## 背景

E 検査で、a·u ≤ 3（4au = 4, 8, 12）の組では指数の不足が起きず、失敗はすべて群の障害でした。この 3 つの群 (ℤ/4au)^× はどの元も 2 乗すると 1 なので、
−1 が使える素因数（4au と互いに素）の生成する部分群に入ることと、実際の約数で −1 を作れることは同じです。そして −1 が部分群に入らないのは、
法 4au の奇な二次指標 χ（χ(−1) = −1）で、使える素因数がすべて ker χ に入るときです。

| 4au | 組 (a,u) | 奇な二次指標 |
|---|---|---|
| 4 | (1,1) | χ₋₄ |
| 8 | (1,2)、(2,1) | χ₋₄、χ₋₈ |
| 12 | (1,3)、(3,1) | χ₋₄、χ₋₃ |

したがって、これらの組に証人があるのは「**各奇な指標 χ について、ap+u の使える素因数 q で χ(q) = −1 となるものがある**」ときに限ります。

## 全体の符号（導出）

使える部分（ap+u から 2 と au の素因数を除いたもの）を k と書きます。6 類の素数は p ≡ 1 (mod 24) を満たすので:

- **(1,1)**: p + 1 = 2k、k ≡ 1 (mod 4)。よって **χ₋₄(k) = +1**。
- **(1,2)**: p + 2 ≡ 3 (mod 8) は奇数で k = p + 2。χ₋₄(k) = −1、**χ₋₈(k) = (−2 | k) = +1**（k ≡ 3 mod 8）。
- **(2,1)**: 2p + 1 ≡ 3 (mod 8)。(1,2) と同じく χ₋₄ = −1、**χ₋₈ = +1**。
- **(1,3)**: p + 3 ≡ 4 (mod 8) なので 2 でちょうど 2 回割れ、p + 3 ≡ 1 (mod 3) なので 3 では割れない。k = (p + 3)/4 ≡ 1 (mod 3) より **χ₋₃(k) = +1**。
  χ₋₄(k) は p ≡ 1 (mod 16) なら +1（k ≡ 1 mod 4）、p ≡ 9 (mod 16) なら −1（k ≡ 3 mod 4）。
- **(3,1)**: 3p + 1 も同様で、**χ₋₃ = +1**、χ₋₄ は p ≡ 1 (mod 16) で +1、p ≡ 9 (mod 16) で −1。

χ(k) は使える素因数の χ の値の積（指数込み）なので、全体の符号が −1 なら χ(q) = −1 の素因数が必ずあります。逆に全体の符号が +1 なら、
χ(q) = −1 の素因数があるとしても偶数個（指数込み）で、なくてもかまいません。

**結論（初等的）**: 6 類の素数 p では、a·u ≤ 3 のどの組にも、全体の符号が必ず +1 になる奇な指標が少なくとも 1 つあります（(1,1) の χ₋₄、(1,2)・(2,1) の χ₋₈、
(1,3)・(3,1) の χ₋₃）。したがって**全体の符号だけで証人の存在が保証される組はありません**。これらの組の成否は、その指標で −1 を取る素因数を
ap+u が（偶数個）持つかどうかで決まります。使ったのは p ≡ 1 (mod 24) と p mod 16 だけです。

これは Mordell の整理（6 類以外は既知の恒等式で解ける）の、小さい a·u の組での姿です。たとえば p ≡ 5 (mod 8) なら p + 1 = 2k で k ≡ 3 (mod 4) となり、
χ₋₄(k) = −1 から (1,1) の証人が必ずあります（PR #7 の `es_of_mod_eight_eq_five` が扱う類）。

## データとの照合

`small_shifts.py` → `small_shifts_results.json`。1,977 素数すべてで p ≡ 1 (mod 24)。5 組 × 各指標の全体の符号は、上の導出と**食い違い 0** でした。
全体の符号だけで保証される組を持つ素数は 0 個。各組の失敗数は (1,1) 1,117、(1,2) 1,160、(2,1) 1,175、(1,3) 1,208、(3,1) 1,197（それぞれ約 57〜61%）で、
5 組すべてが失敗する素数は 127 個（6.4%）でした。

## 読み方（主張ではありません）

- E 検査の示唆（a·u の小さい組に二次指標の評価を当てる）を詰めると、小さい組では「強制された 1 つの指標について、ap+u が χ(q) = −1 の素因数を持つか」
  という 1 本の条件になります。たとえば (1,1) では「(p+1)/2 が 3 (mod 4) の素因数を持つか」で、これを持たない数（素因数がすべて 1 mod 4）は
  平方和で書ける数の一種で、密度は 0 に近づきますが無限にあります。小さい組だけでは全素数は覆えず、a·u を広げた組の同時の評価が要ります。
- 5 組すべてが失敗する 6.4% の素数が、より大きい a·u の組で救われる仕組み（E・X 検査のモデルでは、組どうしはほぼ独立）が、次に詰めるべき部分です。
