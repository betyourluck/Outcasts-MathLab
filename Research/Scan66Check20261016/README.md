## 方法

- `scan66.py`: 篩（bytearray）で p < 10⁸ の素数を列挙し、p mod 840 ∈ {1,121,169,289,361,529} に絞って、各素数を sympy の `isprime` でも確認。
  各 p について E の 81 組すべてで N = ap+u を `factorint`、積の確認、奇約数の生成で W を数え、**剰余の DP でも数えて全行で一致を assert**。
  W > 0 の行は最小の証人 s で N mod s = 0・s ≡ −1 (mod 4au) を因数分解なしで確認。E_log ≤ 2 の素数の全 81 行と 1% の行（種 20261016）で、
  各因数の素数判定と √N までの試し割りによる全約数の列挙を突き合わせた。
- p = 38,296,729 の箱（73 組）と §1 の層の表は、`Research/CertificateRate20261016/gtest.py`（G 検査のスクリプト）と 10-15 の `chars20261015.row` で計算。
  同じ作者の実装なので、項目 7（G 検査との整合）は独立な確認ではない。
- 実行: `python -I scan66.py`（1 プロセス）。ログ `run66.log`。
- 実行時間 1,473 秒（上限 2 時間）、exit 0。篩の素数はすべて `isprime` で確認、DP と生成の W は 14,536,908 行すべてで一致、証明書の失敗 0、
  試し割りと素数判定の突き合わせ 146,100 行（1% 標本 145,219 行 + E_log ≤ 2 の 11 素数の全行）で食い違い 0。
  素数リスト（1 行 1 つ、LF）の SHA256 = `db0621412d2174063bd87f0d0d90564aa803c88c81e4ccad7f4a11cdf596a956`。
