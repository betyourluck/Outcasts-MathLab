### 言えること・言えないこと

- **J1**: 合算した表では、子かどうかと成功との関連は検出されない。ただし入力ごとには揃っていない。
  - 8615161 は子 5 / 35（14%）、子でない 11 / 24（46%）で **p = 0.015**。
  - 84525841 は子 9 / 87（10%）、子でない 11 / 93（12%）で p = 0.82。
  - 向きはどちらも「子のほうが成功しにくい」。契約は 2 入力の表を層別せずに足すと決めていたので、判定は J1-a のままにする。ただしこれは「独立」の根拠としては弱い。8615161 だけを見れば J1-c の向きに有意。
  - J1-a の帰結は変わらない。E₁ の交わり（成功頂点のうち、相互法則で子になるもの）は、成功頂点を数えるだけでは出ない。
- **J2**: 失敗する子の源は、ほぼすべて最初の法 σr で落ちる。法 τ² と結合はあわせて 3.5%。
- **J3（外れ）**: 実指標で説明できる失敗は 1 割に届かない。平方源の枠では、FailureAtlas の箱型（法 4au が小さく、失敗の 91.5% が実指標）と状況が違う。理由は次の「J3 が外れた理由」に書く。

### J3 が外れた理由（紙の導出と、契約の外の集計）

- **σ(r) = 1 のとき、法 σr は素数 r 1 つで、両枝の目標の記号は p と r によらず決まっている。** 4x = p + rτ² ≡ p (mod r) なので、次の 2 つが成り立つ。
  - Type II: (−x ∣ r) = (−1 ∣ r)(p ∣ r) = (−1)(−1) = +1。目標はいつも平方剰余なので、実指標の障害は起きない（G0-5）。
  - Type I: (−px ∣ r) = (−p²/4 ∣ r) = (−1 ∣ r) = −1。目標はいつも非剰余なので、実指標の障害は「x の素因数がすべて法 r の平方剰余」のときだけ起きる。
  - 契約の外の確認: σ = 1 の子の 28,591 源すべてで、この 2 つの記号は成り立った（例外 0）。
- **子の大きさごとの内訳**（契約の外の集計、失敗する子の源 × 枝、2 入力の合算）:
