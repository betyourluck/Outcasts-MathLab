## 記号

- p は 3 入力の素数（6 類 mod 840）。χ(a) = (a∣p)（オイラー基準）。ℓ = 最小の素数非剰余（2521 は 11、他の 2 つは 17）。
- 頂点 q（法 p の非剰余素数 < p）: σ(q) = 1（q ≡ 3 mod 4）/ 3（それ以外）、A_q = σ(q)q。許容 τ = A_q τ² < 3p を満たす正の奇数。
- 源 (q, τ): c = A_q τ²、x = (p + c)/4（整数、0 < x < p、gcd(c, x) = 1 を assert）。D(x²) = x² の約数全部（全指数）。
  - 目標: Type II は t_II = −x、Type I は t_I = −px（どの法でも同じ整数を還元する）。
  - **成功** ⇔ ある d ∈ D(x²) と枝 b で d ≡ t_b (mod c)。頂点の成功 ⇔ 許容源のどれかが成功。G_p = 成功する頂点の集合。
- 根 ℓ、A = A_ℓ。**子** = 根の許容源の x を割る非剰余素数 r（指数に依らない）。R(p) = 子の集合。
- **実際の根 β(r)**: r ∤ A のとき、p + Aτ² ≡ 0 (mod r) の解 τ ≡ ±b のうち奇数の代表（1 ≤ β ≤ r − 2）。>>92 の導出（(p/r) = (r/p) = −1 と相互法則）で、解がある ⇔ (−A/r) = −1、r が子 ⇔ (−A/r) = −1 かつ Aβ² < 3p。
- **短い根の範囲** B(p) = {r : A(r − 2)² < 3p}（>>92 の一律の十分条件）。r_B(p) = その最大の r（2521 で 28、8615161 で 713、84525841 で 2231）。
- **窓** W(p) = {r ≤ r_B(p) : r は非剰余素数、r ≠ ℓ、r ∤ A}。W の中では「子である」⇔ (−A/r) = −1（Aβ² ≤ A(r − 2)² < 3p なので区間の条件は自動で満たされる）。
  窓の大きさと子の数はルジャンドル記号だけで決まるので、契約を書く時点で数えた（成否は見ていない）: 2521 は |W| = 3（{17, 19, 23}、子は 17・19）、8615161 は |W| = 59（子 35）、84525841 は |W| = 180（子 87）。

### 失敗の段階（>>88 の分類を、CRT を仮定しない形に直したもの。→ 訂正 1: >>88 と同じではない）

源 (q, τ) と枝 b について、3 つの法 m₁ = σ(q)q、m₂ = τ²、m₃ = c で「当たり」⇔ ある d ∈ D(x²) で d ≡ t_b (mod m) を調べる。

- **成功**: m₃ で当たり。
- **法 σq**: m₁ で当たりなし。
- **法 τ²**: m₁ では当たり、m₂ で当たりなし。
- **結合**: m₁ と m₂ では当たり、m₃ で当たりなし（gcd(σq, τ²) > 1 の場合もここに入る）。

τ = 1 なら m₂ = 1 で必ず当たり、m₃ = m₁ なので「結合」は起きない。

### 障害の種類（失敗した法 m* で判定）

x の素因数 g はすべて c と互いに素なので、法 m*（c の約数、奇数）の単元。K = ⟨g⟩ ⊂ (ℤ/m*ℤ)^×。

- **実指標の障害**: 法 m* の実指標 ψ（m* の相異なる素因数の部分集合についてのルジャンドル記号の積）で、すべての g で ψ(g) = 1、かつ ψ(t_b) = −1 となるものがある。GF(2) のベクトル（g ごとに、m* の各素因数での記号が −1 の位置を 1 にする）で、目標のベクトルが g のベクトルの張る空間に入らないことと同値。
- **実指標では説明できない**（上が成り立たない）とき:
  - m* が素数なら巡回群なので厳密に分ける: **群の障害**（t_b ∉ K。位数で判定）/ **指数の不足**（t_b ∈ K だが実際の約数で当たらない）。
  - m* が合成数なら **未分割**（複素指標による群の障害と指数の不足をここでは分けない）。

## 判定（2 つの大きい入力で判定する。2521 は小さく既知が多いので記述だけ）

### J1 到達できることと成功の独立性（>>98 の交わり）

W(p) の各 r について、(−A/r) = −1（子）かどうかと、r ∈ G_p（成功）かどうかの 2×2 表を作る。8615161 と 84525841 の表を合算し、両側のフィッシャーの正確検定を行う。

- **見立て: 独立（p ≥ 0.05）**。根拠: r の成功は r 自身の源 x′ = (p + σ(r)rτ′²)/4 の分解で決まり、(−A/r) は根の A だけで決まる。σ(r) = 1 の Type II では法 r の実指標の条件が A に依らないこと（下の G0-5）も、結びつきがない方に効く。確信は中くらい。
- 分岐:
  - **J1-a 独立**: E₁ の交わりは「W の成功頂点のうち、相互法則で半分ほどが子になる」形で、成功頂点の数と、相互法則の条件がそれと独立であることの両方が要る。後者は数えるだけでは出ない（>>92 の指摘と同じ向き）。
  - **J1-b 正の相関**（子のほうが成功しやすい）: 到達と成功を結ぶ構造があり、それを切り出す。
  - **J1-c 負の相関**: 子が不利で、E₁ は数から見るより脆い。

### J2 失敗の段階

2 つの大きい入力の**失敗する子**の全許容源 × 2 枝（合算）で、段階の割合を数える。

- **見立て: 「法 σq」が 60% 以上、「結合」が 5% 以下**。根拠: 子の源の多くは τ が小さく（τ = 1 では法 τ² の段階が自明に通り、結合も起きない）、大きい子ほど法 σr が大きい。2521 の根の 26（源 × 枝）は法 σq が 11、法 τ² が 15、結合 0（>>88）で、根では法 τ² のほうが多かったことも知っている（→ 訂正 1: この契約の定義では 11 / 13 / 2）。確信は中くらい。
- 分岐: **J2-a** 見立てどおり → 子の失敗はほぼ法 σr の局所的な失敗。**J2-b** 法 τ² か結合が見立てより多い → τ² の部分が効いており、そこを調べる。

### J3 障害の種類

J2 と同じ組で、失敗した法での「実指標の障害」の割合を数える。

- **見立て: 50% 以上**。根拠: 箱型の失敗の 91.5% が Kronecker 指標で説明できた（FailureAtlas）、>>61 の第 1 段が 80.9%。ただし平方源の枠では測ったことがないので、確信は低い。
- 分岐: **J3-a** 50% 以上 → 子の失敗の大半は、既に Lean 化した型（ヤコビ記号の障害）の局所版。**J3-b** 50% 未満 → 実指標で説明できない障害（素数の法では群 / 指数、合成数の法では未分割）が主で、複素指標や指数の側を調べる。
