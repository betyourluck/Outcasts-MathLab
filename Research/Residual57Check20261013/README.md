## 方法

- `check57_cert.py`: 定義から自前実装（sympy で因数分解・原始根・円分多項式・Jacobi 記号、`fractions` で厳密な有理数）。
  法 m = 4au の指標は CRT で巡回成分に分けて列挙し、**乗法性を全単数の組で検査**、直交性
  $W_i=\frac1{\varphi}\sum_\chi\chi(-1)F_\chi$ が**整数の割り算による約数列挙**の $W_i$ と全行で一致することを assert で確かめた
  （複素数の浮動小数でも同じ和を検算）。$F_\chi$ は 1 の原始 L 乗根の整数多項式として持ち $\Phi_L$ で簡約（L = 指標群の指数）。
  共役対の符号つき多項式 $\chi(-1)(F_\chi+F_{\bar\chi})$ が定数ならその値、定数でなければ係数の絶対値和の負を $\ell_{ij}$ とする
  （>>57・README の規約。基底依存の保守的な下界）。
- 入力は相手と同じ固定の 2 箱（p = 66529: B = 17、互いに素な 43 組 / p = 18490201: B = 25、69 組）と補助の 1 行（p = 1201、(3,1)）。
- 相手の `residual-audit-results.json`・`residual-audit-rows.json` は**計算後に読み込んで照合にだけ使う**（引数で渡す）。
- `delta58_check.py`: >>58 の恒等式を自分の行データで検査。
- Lean: `ResidualAccounting20261013.lean` を `b84bbb7` の blob から取り出し、この作業ツリーの Lean 4.34.0 / Mathlib `5ed2965` で
  `lake env lean -j 1`（`LEAN_NUM_THREADS=1`）により**単体コンパイル**。lake build ではないのでキャッシュの再生（Replayed）は関係ない。
