## 記号と規約（>>57・README から写す。等価だが独立に実装する）

- N = ap+u、m = 4au、φ = φ(m)。奇部分 N_odd の素因数分解 q^e（指数は実際の値）。
- W_i = #{s ∣ N : s ≡ −1 (mod m)}。**整数の割り算による全約数列挙**と、素因数分解からの生成の 2 通りで数え、一致しなければ止まる。
- 法 m のディリクレ指標 χ は (Z/m)^× の指標全部（φ 個）。実装は CRT で巡回成分に分け、各成分の生成元の像で表す
  （相手も同じ方式。独立性は「コードを写さない」ことで担保し、正しさは (i) 乗法性の検査 (ii) 直交性 W_i = (1/φ) Σ_χ χ(−1) F_χ が
  約数列挙の W_i と**全行で一致**することで担保する）。
- F_χ = Π_{q^e ∥ N_odd} (1 + χ(q) + … + χ(q)^e)。値は 1 の原始 L 乗根 ζ_L（L = 指標群の指数 = 巡回成分の位数の lcm）の
  整数係数多項式で持ち、Φ_L で簡約した標準形（次数 < φ(L)）で表す。
- 区別する奇な実指標 χ₀ = χ_{−au}（単数 r 上で Jacobi (−au | r)）。t_i = F_{χ₀}/φ、U_i = τ_odd/φ、V_i = U_i − t_i。
- 実指標は F_χ ≥ 0（整数）。A_i = Σ_{非自明な偶実指標} F_χ/φ、B_i = Σ_{χ₀ 以外の奇実指標} F_χ/φ。
- 複素指標は共役対 {χ, χ̄} にまとめ、符号つき対の多項式 c = χ(−1)·(F_χ + F_{χ̄}) を Φ_L で簡約する。
  **ℓ_ij** = c が定数ならその値、定数でなければ −Σ_k |c_k|。C_i = Σ_j (c_j の値)/φ（厳密、これは定数になるはず）。
- H_i = A_i − B_i + Σ_j ℓ_ij/φ、**K_i = min{V_i, (−H_i)₊}**、証明書の下界 Σ(V_i − K_i)。
  相手の行ごとの `factor_only_W_lower` = max(0, V_i + H_i) も計算して照合する（箱の和 4・2）。
- 分解の検査: W_i = V_i + A_i − B_i + C_i が全行で成立すること。
- r_i = (V_i − W_i)₊、Δ_i = t_i − min{t_i,(U_i − W_i)₊}。r_i ≤ K_i ≤ V_i を全行で確かめる。
