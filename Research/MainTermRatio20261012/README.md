# MainTermRatio20261012 — 固定した p での「主項」と実際の証人の数（探索、判定ではない）

有限計算です。Lean では検証していません。Outcasts >>53 で挙げた「固定した $p$ の箱の中で主項と誤差の和を取る」読みの下準備として、
公開済みの行（X・Y・E・S・Q・H 検査、$4\cdot10^6<p<1.6\cdot10^7$ の 6 類の素数 23,177 個、互いに素な $au\le\lceil\log_2p\rceil$ の 1,517,553 組）で、
証人の数 $W(p)=\sum_{(a,u)}\#\{s\mid ap+u:\ s\equiv-1\ (\mathrm{mod}\ 4au)\}$ を、指標展開の項と並べました。**探索なので判定はありません。**
見立てはこのデータで作ったので、確認は新しい範囲で契約を固定してから行う必要があります。

## 何を数えたか

$m=4au$、$M=ap+u$ の奇数部分の約数 $s$ について、$W=\frac1{\varphi(m)}\sum_{\chi\bmod m}\chi(-1)\prod_{q^e\,\|\,M_{\mathrm{odd}}}(1+\chi(q)+\cdots+\chi(q)^e)$ です。

| 記号 | 中身 |
|---|---|
| $W$ | 実際の証人の数（約数を剰余ごとに数えて得る。公開済みの証人の有無と 1,517,553 組すべてで一致） |
| $M_t$ | 自明な指標の項 $\tau(M_{\mathrm{odd}})/\varphi(4au)$（奇数の約数が $(\mathbb Z/4au)^\times$ に一様に散っていれば期待される数） |
| $M_{t2}$ | $M_t$ に、**奇な実指標 $\chi_{-au}$ の項**を足したもの: $\big(\tau(M_{\mathrm{odd}})-\prod_q(1+\chi(q)+\cdots+\chi(q)^e)\big)/\varphi(4au)$。$q\mid ap+u$ なら $(p\mid q)=(-au\mid q)$ なので、素因数の上では $\chi_{-au}(q)=(p\mid q)$（Euler の基準で計算）。$\chi_{-au}(-1)=-1$ |
| $M_{t3}$ | $M_{t2}$ で $\chi(q)$ を公平な硬貨（$\pm1$ が各 $1/2$）に置き換えた期待: $\big(\tau-\prod_q\frac{(e+1)+[e\text{ 偶数}]}{2}\big)/\varphi(4au)$ |

$(1,1)$（$m=4$）では $W=M_{t2}$ が恒等式で、スクリプトはこれを全行で確認して止まる条件にしています。

## 見えたこと

| | 全体 | X（4–5·10⁶） | H（1.3–1.6·10⁷） |
|---|---|---|---|
| 平均 $W$ | 24.7 | 22.6 | 26.1 |
| 平均 $M_t$ / 比 $W/M_t$ | 44.0 / **0.558** | 41.5 / 0.542 | 45.5 / 0.569 |
| 平均 $M_{t3}$ / 比 $W/M_{t3}$ | 38.0 / 0.645 | 35.6 / 0.631 | 39.5 / 0.656 |
| 平均 $M_{t2}$ / 比 $W/M_{t2}$ | 26.3 / **0.938** | 24.2 / 0.934 | 27.7 / 0.940 |
| $W/M_{t2}$ の分位（0.1% / 1% / 50% / 99%） | 0.44 / 0.59 / 0.94 / 1.28 | 0.45 / 0.56 / 0.94 / 1.26 | 0.45 / 0.59 / 0.94 / 1.28 |
| $W-M_{t2}$ の平均 / 標準偏差 | −1.59 / 3.58 | — / 3.28 | — / 3.70 |
| $\mathrm{corr}(W,M_t)$ / $\mathrm{corr}(W,M_{t2})$ | 0.61 / 0.85 | | |
| 順位相関 with $n_2(p)$: $W/M_t$ / $M_{t2}$ / $W/M_{t2}$ | −0.27 / −0.30 / **+0.07** | | |

1. **自明な指標の項は主項ではない。** $W/M_t$ は平均 0.56 で、範囲（$p$ の大きさ）にも組 $(a,u)$ にもほとんど依らず 0.5〜0.6 に揃う（$\varphi(4au)=2$ の $(1,1)$ から $\varphi=44$ まで）。
   「誤差」は打ち消し合う揺らぎではなく、系統的な $-44\%$。
2. **奇な実指標 $\chi_{-au}$ の項 1 つで、系統的な分の大半が説明できる。** $W/M_{t2}$ は平均 0.94、中央値 0.94。この項は常に 0 以下で、
   素因数 $q$ が $p$ の平方剰余（$\chi(q)=+1$）に偏るほど大きい。$n_2(p)$ 未満の素数は必ず剰余なので、$n_2(p)$ が大きい素数ほど $M_{t2}$ が小さい
   （順位相関 $-0.30$）。**H 検査で見た $n_2(p)$ の効果は、この項に全部入る**（$W/M_{t2}$ と $n_2$ の順位相関は $+0.07$）。
3. **公平な硬貨では足りない。** $\chi(q)$ が公平な $\pm1$ なら $W/M_{t3}=0.65$ までしか下がらない。残りは、$ap+u$ の実際の素因数（特に小さい素数）で
   $(p\mid q)=+1$ が多いことによる。6 類の素数では $2,3,5,7$ が剰余で、$q\mid ap+u$ の確率は小さい $q$ ほど大きい。
4. **残りの $-6\%$ は $\varphi(4au)$ が大きい組に集中**: $\varphi\le8$ の組では $W/M_{t2}=0.96$〜$1.03$、$\varphi=16,32$ の組では $0.77$〜$0.98$。
   他の実指標（$\chi_4$、$\chi_8$、$(\cdot\mid\ell)$ for $\ell\mid au$）も、小さい素因数の上では値が固定なので、同じ種類の偏りを持つと見込む（未検証）。
5. **下側の尾**: $W=0$ の素数は無し。最小は $W=4$（$p=5843041$、PR #4 の積型反例の素数。$M_t=41.9$、$M_{t2}=19.4$、$W/M_{t2}=0.21$）。
   $W/M_{t2}<0.5$ は 23,177 個中 0.1% 点より下。$p$ が大きくなるにつれ $W$ も $M_{t2}$ も増え（予算 22→24、$\tau$ も増える）、比の分位は動かない。
6. **同じ $p$ の組どうしの揃い**: $\mathrm{Var}_p(W-M_t)$ と $\sum_{(a,u)}\mathrm{Var}(W-M_t)$ の比は 1.05〜1.12（弱い正の揃い。$p$ の小さい素数での剰余が組をまたいで共有されるためと見込む）。

## 読み方（主張ではありません）

- 固定した $p$ で篩型の下界を出すなら、主項は $\tau/\varphi$ ではなく、少なくとも $\chi_{-au}$ の項（= 素因数の $(p\mid q)$ で決まる）を含む必要がある。
  この項は $p$ の剰余データ（どの小さい素数が平方剰余か）で決まるので、「主項」自体が $p$ ごとに違う。
- $M_{t2}$ の後に残る揺らぎ（標準偏差 3.6、$W$ の約 14%）の下側の尾が、点ごとの保証に関わる量。23,177 個の最小は $0.21$。
- H11 のモデル（$B$ 以下の素因数の剰余を与件、大きい素因数は積の制約つき一様）は、この指標の項を含むすべての指標の項の期待を取ったものにあたる。
  $M_{t2}$ はその「1 指標版」で、閉じた式で書ける。

## 主張しないこと

独立の証明、存在補題、標本外の素数への保証。判定基準は固定していないので、ここの数値はすべて見立て。
