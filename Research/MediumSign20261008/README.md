# MediumSign20261008 — 中くらいの素因数の符号の偏りは何で決まるか（Y 検査）

有限計算です。Lean では検証していません。X 検査（`../Character20261008/`）で、二次指標の障害は 1000 以下の素因数の符号を与件にすれば
公平な硬貨のモデルで記述でき、23〜1000 の素因数の符号は −1 に偏っていました。その偏りの原因を調べました。

## 調べた説明

中くらいの素数 q（29〜997、4au と互いに素）が ap+u を割るかどうかは、p について確率 1/(q−1) の出来事のようにふるまい、
割ったときの符号は χ_d(q) = (d | q) で固定されている。したがって符号の平均は

S_pred(d) = Σ_q χ_d(q)/(q−1) ÷ Σ_q 1/(q−1)

になる、という説明です。これが成り立てば、偏りに p の深い構造は要らず、有限の指標和で決まります。

## 契約と順序

- 契約 `contract.md` を計算の前に fork へ push しました（コミット `0e7ac68`、2026-10-08T09:12:17Z ごろ）。X 検査の範囲で見た値は契約に書いてあります。
- 計算は 2026-10-08T09:12:44Z に始めました（14 秒）。別のディレクトリでもう一度実行し、結果（所要時間を除く）と全行データが一致しました。

## 入力

5·10⁶ < p < 6·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529} の素数 1,985 個（どの既存の範囲とも重ならない）。互いに素な (a,u)、a·u ≤ 23 で 125,055 行。
成否の約数は 2 方式で全行一致（試し割りの素数表は 20,000 まで。この範囲の平方根は最大 11,747）。

## 測定

素数の範囲を分けた全体の値: 29〜100 で観測 −0.0592 / 予測 −0.0570（−0.9 SE）、101〜997 で −0.0405 / −0.0379（−1.2 SE）。上位 20 個の d は `mediumsign_results.json`。

## 読み方（主張ではありません）

- 中くらいの素因数の符号の偏りは、「どの素数が割るかは確率 1/(q−1)、符号は固定された指標値」という単純な説明で、この範囲では足りました。
  偏りは d によって正にも負にもなり（d = −22、−30 では正）、全体では負に傾いています。有限の和 Σ χ_d(q)/q が負になりやすいこと
  （小さい判別式で L(1, χ_d) が小さいこと）と整合しますが、その関係はこの検査では確かめていません。
- X 検査とあわせると、二次指標の障害は「p の剰余で決まる全体の符号」「割る確率 1/(q−1) で現れる、符号の固定された素因数」「大きい素因数の公平な硬貨」で記述できます。
  存在補題の (B)(i) を確率的な形で考えるときの、素因数の符号のモデルとして使える形です（証明ではありません）。

## 主張しないこと

存在補題、L(1, χ_d) との関係の証明、偏りの漸近的なふるまい。
