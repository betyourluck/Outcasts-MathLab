# P1 / Y: 中くらいの素因数の符号の偏りは「割る確率 1/(q−1) × 固定された指標値」で説明できるか — 事前登録の契約（2026-10-08、計算前に固定）

（名前: 「Y 検査」。判定を Y1〜Y3、測定を Y4 とする。）

## 動機

X 検査（`Research/Character20261008/`）で、二次指標の障害は境目 T = 1000 の硬貨モデルで記述でき、T = 23 では障害が硬貨より少なかった。
つまり 23〜1000 の素因数の符号 (d | q) が −1 に偏っている。その原因の候補として、次の単純な説明を調べる。

> 中くらいの素数 q が ap+u を割るかどうかは、p について確率 1/(q−1) の出来事のようにふるまい（p は q で割り切れないので、ap+u ≡ 0 となる p の剰余類は (q−1) 個中 1 個）、
> 割ったときの符号は χ_d(q) = (d | q) で固定されている。したがって、中くらいの素因数の符号の平均は
> S_pred(d) = Σ_q χ_d(q)/(q−1) ÷ Σ_q 1/(q−1)（q は 29〜997 の素数で 4au と互いに素なもの）になる。

この説明が正しければ、偏りに p の深い構造は要らず、有限の指標和（Σ χ_d(q)/q が負に傾きやすいこと）で決まる。

## すでに見ているもの（正直に）

X 検査の範囲（4·10⁶ < p < 5·10⁶、公開済み）で、計算前に見た: 中くらいの素因数の符号の平均は全体で観測 −0.0465（出現 374,996 回、標準誤差 0.0016）、
予測 −0.0466。出現の多い 12 個の d で、観測と予測の差は概ね標準誤差の 2 倍以内（例: d = −2 で −0.109 対 −0.113、d = −14 で −0.208 対 −0.204、
d = −22 で +0.126 対 +0.136）。**判定は、まだ計算していない新しい範囲だけで行う。**

## 入力（固定）

- 素数: 5·10⁶ < p < 6·10⁶、p mod 840 ∈ {1, 121, 169, 289, 361, 529}（1,985 個。個数を数えただけ）。どの既存の範囲とも重ならない。
- 箱: 互いに素な (a,u)、a·u ≤ ⌈log₂ p⌉（この範囲では全部 23）。X 検査と同じ規約。
- 因数分解は試し割り（素数表は 20,000 まで。この範囲の ap+u の平方根は最大 11,747）。成否の約数は 2 方式で照合する。
- d: 負の平方因子なしの d（−d | 2au）。中くらいの素数: 29 ≤ q ≤ 997 の素数で 4au と互いに素なもの。

## 統計量

行 (p,a,u) と d の組ごとに、ap+u を割る中くらいの素数 q それぞれについて符号 χ_d(q) を数える（出現 1 回につき 1 つ。指数は数えない）。
- 観測 S_obs(d) = 符号の平均、その標準誤差 SE = √((1 − S_obs²)/n)（n は出現回数。出現を独立とみなす近似）。
- 予測 S_pred(d): 上の式を、同じ (行, d) の組すべてについて重み 1/(q−1) で足し合わせたもの（実際に割るかどうかは使わない）。
- 全体（全 d をまとめた値）も同じ方法で出す。

## 判定（事前登録）

- **Y1（主、予測）**: 全体で |S_obs − S_pred| ≤ 3·SE。
- **Y2（予測）**: 出現回数の多い上位 12 個の d のうち、|S_obs(d) − S_pred(d)| > 3·SE(d) となるものは 1 個以下。
- **Y3（理屈の確認）**: ap+u を割る使える素数 q（4au と互いに素、q ≠ p）すべてで、(−au | q) = (p | q)（PR #6 L2 の関係。ap ≡ −u (mod q) から従う）。
  違反 0 件。1 件でもあれば実装の誤りとして止める。

## 測定（判定に使わない）

- **Y4**: d ごとの S_obs・S_pred・出現回数（上位 20 個）。中くらいの素数を 29〜100、101〜997 に分けた全体の S_obs と S_pred。

## 止める条件と上限

成否の 2 方式の不一致、Y3 の違反で止める。1 プロセス、乱数なし、上限 60 分。範囲・箱・q の範囲は広げない。

## 主張しないこと

存在補題、L(1, χ_d) との関係の証明。Y1・Y2 が成り立っても、言えるのは「この範囲・この箱では、中くらいの素因数の符号の偏りは、
割る確率 1/(q−1) と固定された指標値で説明できる」までで、偏りの漸近的なふるまいは主張しない。
