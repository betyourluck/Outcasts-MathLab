# Stratified20261008 — J 検査の層別の較正（Outcasts >>42 への応答、C 検査）

有限計算です。Lean では検証していません。Outcasts >>42 の指摘（全体の較正 J0 は層ごとのずれの打ち消し合いを見逃しうる。層ごとのずれは J1 の判定に効きうる）
に応えて、J 検査（`../JointFailure20261008/`）のモデルの較正を層ごとに調べました。

## 契約と順序

- 契約 `contract.md` を計算の前に fork へ push しました（コミット `83f3bed`、2026-10-08T11:26:32Z ごろ）。層と判定基準はそこで固定しています。
- 最初の実行（11:27:07Z）は、判定を書く前にスクリプトの不具合で止まりました（`failed-run-1.log`）。大きい素因数が 2 個以上でも P がちょうど 0 か 1 になる行は
  P_i の区間（端点を含まない）に入らず、C3 の表を並べ替えるところで落ちました。契約どおりその行は P_i の区間の層から外したまま、C3 では「P = 0 / 1」の層として扱うよう直し、
  11:29:14Z に再実行しました（163 秒）。別のディレクトリでもう一度実行し、結果（所要時間を除く）が一致しました。
- 入力は J 検査の確認用データ（10⁶ < p < 2·10⁶）で、新しい範囲は使っていません（問いが J 検査そのものの頑健さなので）。

## 測定

- **C3（再較正した J1）**: 計算方法 × P_i の区間ごとに P_i に観測 / モデルの比を掛けて [0, 1] に切り詰め、J1 を計算し直しました（ブートストラップ 2,000 回、種 20261012）。

  | | T₂ | T₃ | T₄ |
  |---|---|---|---|
  | J 検査（元のモデル） | Z −1.66、p = 0.097 | Z −0.48、p = 0.635 | Z 0.15、p = 0.850 |
  | 再較正 | Z −1.89、p = 0.054 | Z −0.64、p = 0.516 | Z −0.10、p = 0.946 |

  再較正しても、どれも p ≥ 0.01 で、**J1 の判定（独立モデルとの違いは見えない）は変わりません**。T₂ は負の向きのまま、やや 0.01 に近づきました。
- **C4**: 探索用の標本（p < 10⁶、B = 23）でも同じ型のずれ（P_i ∈ (0.3, 0.5] で z −7.62、(0.9, 1) で +7.75、u ≤ 6 で −7.28、u = 11〜23 で +6.62）。
  確認用データを B = 100 で計算すると、ずれは大きく縮み、基準を超えそうなのは P_i ∈ (0.3, 0.5]（z −3.98）と u ≤ 6（z −3.74）だけでした。

## 読み方（主張ではありません）

- 層ごとのずれの主な原因は、B = 23 のモデルが 29〜100 の素因数の剰余を一様とみなしていることだと読めます（B = 100 で大きく縮む。X・Y 検査で
  「中くらいの素因数の剰余・符号は固定されていて、一様ではない」と見たのと同じ種類）。u ≤ 6 の組は法 4au が小さく、こうした素因数の影響を受けやすいと考えられます。
- それでも、層ごとに再較正した P で J1 の判定は変わらなかったので、「この有限範囲・k ≤ 4 の統計量では、同時失敗の低次の構造は検出されなかった」という
  J 検査の結論は、このずれによっては崩れていません。ただし、モデルの誤差を完全に評価したわけではありません（再較正は層ごとの 1 つの比で、層の中のずれは残ります）。
