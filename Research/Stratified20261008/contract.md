# J 検査の層別の較正（Outcasts >>42 への応答）— 事前登録の契約（2026-10-08、計算前に固定）

（名前: 「C 検査」。判定を C0〜C2、測定を C3・C4 とする。）

## 動機

Outcasts >>42 の指摘: J 検査（`Research/JointFailure20261008/`）の較正 J0（全体の Σ S_p / Σ E_p = 1.0115）は、層ごとの過大評価と過小評価が
打ち消し合っても通る。J1 のブートストラップは与えた P_i が正しいことに条件づけているので、層ごとの較正のずれは、組間の依存を隠したり見かけの
依存を作ったりしうる。そこで、層を計算前に固定して、層ごとに観測した失敗の数と モデルの期待値を比べる。

## すでに見ているもの（正直に）

J 検査の確認用データ（10⁶ < p < 2·10⁶、2,149 素数、公開済み）の全体の値（S/E = 1.0115、T₂ = −146.44 など）と、
感度の B = 7・100 の全体の値。**層ごとの集計は一度も計算していない。** 新しい範囲は使わない（>>42 の問いは J 検査そのものの頑健さなので）。

## 入力（固定）

- J 検査の確認用データの全行（`Research/JointFailure20261008/confirmatory_rows.json.gz`、113,897 行）。
- モデル: J 検査と同じ（H11 の `model`、B = 23、L ≥ 3 のモンテカルロは 1 セル 10,000 標本、種 20261008）。行を同じ順で処理し、**最初に J 検査の
  全体の値（S/E = 1.0115、T₂ = −146.44）が再現されることを確かめる**。再現しなければ止める。
- 失敗 f_i ∈ {0,1}、モデルの失敗確率 P_i。

## 層（固定）

1. 計算方法: 決定的（23 より大きい素因数が 1 個以下、P ∈ {0,1}）/ 厳密（2 個、G の全数え上げ）/ モンテカルロ（3 個以上）。
2. P_i の区間（決定的な行を除く）: (0, 0.1]、(0.1, 0.3]、(0.3, 0.5]、(0.5, 0.7]、(0.7, 0.9]、(0.9, 1)。
3. ω(ap+u)（相異なる素因数の数）: 1、2、3、4、5 以上（決定的な行を除く）。
4. 箱の部分: P1 の 23 組（a,u ≤ 6）/ H2' の 30 組（u ∈ {11,13,17,19,23}）（決定的な行を除く）。

層ごとに O = Σ f_i、E = Σ P_i、V = Σ P_i(1 − P_i)、z = (O − E)/√V（行を独立とみなす近似）、O/E を出す。

## 判定（事前登録）

- **C0（再現）**: 全体の S/E と T₂ が J 検査の値と一致（小数第 4 位まで、T₂ は小数第 2 位まで）。一致しなければ止める。
- **C1（決定的な層）**: 決定的な行でモデルと観測の食い違いが 0 件（J 検査で確認済みの性質の再確認）。
- **C2（主）**: 層 2〜4 の非決定的な層（合計 K 個、K は空の層を除いて数える）のうち、|z| > z* となる層の数。z* は両側 0.01/K の正規分位点（Bonferroni）。
  0 個なら「層別でも大きな偏りは見えない」、1 個以上ならその層と向きを報告する。

## 測定（判定に使わない）

- **C3（再較正した J1）**: 層 1 × 層 2（計算方法 × P_i の区間）ごとに P_i に O/E を掛けて [0, 1] に切り詰めた P′_i で、J1 の T₂・T₃・T₄ と
  ブートストラップの両側 p 値（2,000 回、種 20261012）を計算し直す。判定（p ≥ 0.01 か）が変わるかを並べる。
- **C4**: 同じ層別の集計を、J 検査の探索用の標本（p < 10⁶）と、感度の B = 100 でも並べる。

## 止める条件と上限

C0 の不一致で止める。1 プロセス、上限 60 分。範囲・モデル・層は変えない。

## 主張しないこと

独立の証明、存在補題。C2 で偏りが見えなくても、言えるのは「この有限範囲・この層の切り方では、低次の同時失敗の構造と層別の較正のずれは
検出されなかった」までで、標本外の素数への保証ではない。
